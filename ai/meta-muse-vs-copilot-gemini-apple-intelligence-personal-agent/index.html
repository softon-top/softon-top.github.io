Meta Muse 入局个人 AI Agent:与 Copilot、Gemini、Apple Intelligence 差异化在哪

2026-09-09，星期三

昨晚 Meta 发布 Muse——号称"世界首个面向所有人的个人 AI Agent"。18+、美国先上、可通过独立 app 或 WhatsApp 用。

刷 Hacker News 首页四条同时挂 Muse,评论区分成两派:一派觉得又是大厂 PR 秀,一派觉得这次是真的把 agent 塞进 messaging 入口了。

我盯着这四家的公开资料翻了两个小时,得出一个反直觉的结论:

TL;DR

  • 四家路线完全不同:Meta 押独立 VM+messaging 入口,Microsoft 押企业级编排(Copilot Studio),Apple 押系统级 App Intents 让 Siri 变 agent,Google 已悄悄放弃独立 agent 产品(Mariner 5月4日 discontinued)
  • Muse 最大差异化不是模型,是Muse Secure VM——每个用户单独一个虚拟机隔离数据,年底还要上 Confidential VM(端到端加密,连 Meta 都读不到)
  • Copilot 已经跑通企业场景,面向普通消费者体验落后 Muse 一档;Meta 反过来消费者体验强,企业能力弱
  • Apple 战术最保守也最长期:不做独立 agent 产品,把 agent 能力灌进操作系统本身,让每个 app 都变成 agent 的手脚
  • Google 战术已崩:Mariner 项目组被拆散,browser agent 竞赛认输,capabilities 塞进 Gemini Agent 兜底

四家凑齐了,但打法完全不一样

大厂在 personal AI agent 上有四种截然不同的战术,每种都是根据自家生态位算出来的最优解。

厂商 产品 路线 入口 隔离方案 最强场景
Meta Muse 独立 agent + 强隔离 WhatsApp / Muse app Muse Secure VM(独立虚拟机) 消费级日常任务代办
Microsoft Copilot / Studio Agent 编排平台 Teams / M365 / Studio 租户级 + Entra Agent ID 企业工作流自动化
Apple Apple Intelligence + Siri 系统级 agent Siri / 系统 On-device / Private Cloud Compute 跨 app 意图执行
Google Gemini Agent 融合到助手 Gemini app 云端 VM 兜底 + Google 全家桶联动

一句话四家精气神:Meta 卷入口,Microsoft 卷企业,Apple 卷系统,Google 掉队补作业。

为什么 Muse 敢单独造 VM?

Meta 官方博客里,反复强调的不是模型多强,是Muse Secure VM。

“Because personal agents need a new kind of secure computer, Muse runs on Muse Secure VM, a dedicated, virtual machine (VM) that houses both the agent and a person’s data.”

翻译成人话:一个用户,一台虚拟机。你的 agent 只跑在你的 VM 里,你的数据也只落在你的 VM 里。别人不 share,底层不 share。

年底还要上 Muse Confidential VM——整台 VM 里的数据和对话用只有你持有的密钥加密,Meta 自己都读不到。

这个技术选择很反直觉。为什么?

因为 Meta 有一个死结:过去二十年,大家最不信任的科技公司之一就是 Meta。剑桥分析案、广告投放丑闻、“whether Facebook makes teenage girls hate themselves” 内部文档——这些账 Meta 没还完。

现在 Meta 想推 personal agent,意味着要用户把日程、密码、账户、意图全交给它。用户第一反应就是:“这不就是数据吸尘器 2.0?”

VM 隔离 + 端到端加密就是为了砸掉这个第一反应。技术上给自己上一副手铐,才可能让用户敢用。

对比一下 OpenClaw 之类的开源 agent 框架:每个 agent 天然就有自己的 workspace、AGENTS.md、session 历史,完全隔离是默认状态。Meta 现在做的,其实是把开源社区已经跑通的隔离模式,重新包装成企业级产品卖给消费者。

Copilot 为什么消费级落后 Muse 一档?

Microsoft 是四家里最早搞 agent 的,2024 年 11 月就在 Ignite 官宣 Copilot Actions。到 2026 年,Copilot Studio 已经是相当完整的编排平台:

  • Computer Use agents(Claude Sonnet 4.5 beta 加持)——真正的桌面自动化
  • Multi-step workflows with API actions + approvals + business logic
  • Microsoft Entra Agent ID——每个 agent 都有企业身份
  • Analytics Viewer role——运维可视、职责隔离
  • Remote MCP servers 支持,标准化 tool 连接

但这些都是给 IT/开发者/企业买单的。你让打工人拿 Copilot Studio 帮自己订机票、买菜、跟老婆商量周末去哪玩——门都没有,这套东西根本不是给消费者玩的。

Microsoft 的战术很清楚:先赚企业的钱,消费级慢慢来。消费级入口是 Windows 里的 Copilot 侧栏,能力远不如 Muse 的"发起对话就能开始 goal planning"直觉。

对读者的启示:如果你是打工人、要跑重复企业流程,Copilot Studio 是当前唯一成熟方案。但如果你要个人日常代办,Muse 上手成本低一档。

Apple 为什么不做独立 agent 产品?

Apple 是四家里战术最保守的,但也可能是最长期主义的。

Apple 至今没有一个独立的"Apple AI Agent"产品。iOS 26 推出的是 Apple Intelligence 这一整套系统级能力,agent 的核心表达是 App Intents 框架——让每个 app 都可以把自己的能力"报备"给 Siri。

举个例子:

// 一个 note app 声明它可以创建笔记
struct CreateNoteIntent: AppIntent {
  static var title: LocalizedStringResource = "Create Note"

  @Parameter(title: "Content")
  var content: String

  func perform() async throws -> some IntentResult {
    // 实际业务逻辑
    return .result()
  }
}

用户对 Siri 说"帮我记一条:明天九点开产品会",Siri 通过 App Intents 匹配到 note app,调用 CreateNoteIntent,内容 = “明天九点开产品会”。无需 UI 交互,无需打开 app。

Apple 的战术核心是:

  1. 不做单独 agent 产品——不给自己造"新入口"负担
  2. 把 agent 能力灌进 OS——第三方 app 主动向系统报备,系统统一路由
  3. 隐私默认 on-device + Private Cloud Compute 兜底——不用信任任何一家公司的服务器
  4. 让每个 app 都变成 agent 的手脚——生态复利效应

副作用:iOS 上"AI 体验"感知不强,Siri 至今在很多任务上比 ChatGPT 智障。但如果 App Intents 生态跑通,Apple 手里握的是 30 亿设备上的 agent 底座,而不是一个孤零零的 app。

我实测下来的账本:目前 App Intents 支持的场景还很局限,Siri 处理复杂多步任务的成功率明显不如 Muse。但看长远,Apple 押的是**“agent 是 OS 能力,不是产品”**——这个赌注比 Meta 更狠。

Google 为什么已经掉队?

Google 是四家里剧本最尴尬的。

时间线:

  • 2024 年 12 月:Project Mariner 首次亮相,Google DeepMind browser agent 原型
  • 2025 年 5 月:Google I/O 官宣 Mariner 商业化,支持 10 个 tab 并行,Ultra 订阅可用
  • 2026 年 5 月 4 日:Project Mariner discontinued
  • 2026 年下半年:Mariner capabilities 塞进"Gemini Agent"

Wired 8 月的报道更狠:Google Labs 里做 Mariner 的核心团队被拆分,一些人转岗去更"high-priority" 项目。

为什么 Google 会掉队?

核心问题:browser agent 战场,Chrome 是包袱不是资产。让 agent 接管浏览器,意味着重构 Chrome 的整个交互逻辑。而 Anthropic 的 Claude Computer Use、OpenAI 的 Operator、Microsoft 的 Copilot Actions 都在跳过浏览器,直接做桌面 agent。

Google 押 browser 战术,变成"用大炮打蚊子"——技术门槛高、用户体验差、和 ChatGPT 的产品直觉差太远。

现状:Google 的 agent 战术变成**“能力有,但没独立产品”,** 靠 Gemini Agent 兜底、Google 全家桶联动挽尊。要跟 Muse、Copilot、Apple Intelligence 掰手腕,已经没牌了。

我实测下来的四家对比

我根据公开资料 + 部分体验,评估四家在消费级场景的当前分数(1-5,5 最强):

维度 Meta Muse Copilot Apple Google
消费级入口直觉 5 2 3 3
企业级工作流 1 5 2 3
隐私隔离机制 4(VM) 3 5(on-device) 2
生态复用潜力 2 4 5 4
现有落地成熟度 3 5 2 3
综合(消费者) 3.0 3.8 3.4 3.0
综合(打工人) 2.2 4.6 3.0 3.0

Muse 是消费级新玩家里最激进的,但综合分不高——因为它还是"新产品",生态没铺开、企业不敢用。

Copilot 是"最全能选手"——不管消费级还是企业级都能打,只是消费级体验没 Muse 那么直觉。

Apple 是"长期主义者"——现在打不过,但 5 年后可能全赢。

Google 是"掉队补作业"——除非 Gemini 4 / 5 有质变,否则很难翻身。

落地场景怎么选?

对读者的实操建议:

如果你是普通消费者(排日程、买东西、订餐) 选 Muse(在美国),或者 Copilot 消费者版兜底。Muse 的 WhatsApp 入口零学习成本。

如果你是打工人(跑企业流程、公司规范、数据敏感) 无脑 Copilot Studio。M365 生态 + Entra ID + 企业级 audit,没竞品。

如果你是重度 iPhone/Mac 用户 等 Apple Intelligence 生态成熟。先别指望 Siri 变神,把 App Intents 支持的 app 用起来(Agenda、Fantastical、Things、备忘录等)。

如果你是重度 Google 全家桶用户 Gemini Agent 兜底,但别抱太高期望。可以关注 Anthropic Claude Computer Use 或 OpenAI Operator 作为补充。

常见问题

Q1: Muse 什么时候来中国?

A: 目前 Meta 官方只放开美国 18+ 用户。中国大陆没有 Meta 服务,预计不会直接开放。海外华人可以通过 WhatsApp 尝试,但需美国 Meta 账号 + 美区 App Store。

Q2: Muse 免费吗?收费吗?

A: 官方博客未提定价。参考 Meta AI 的策略,消费级基础版大概率免费(靠 WhatsApp 生态锁定用户),高级功能(比如 Confidential VM、更复杂的自动化)可能后续订阅制。

Q3: Muse 会取代 ChatGPT/Claude 吗?

A: 不会替代,场景不同。ChatGPT/Claude 是通用对话 + 编程 agent,Muse 是消费级日常任务代办。就像微信不会取代 IDE,两者服务不同群体不同任务。

Q4: 我怕数据泄露,能信 Muse 的 VM 隔离吗?

A: Muse Secure VM 是技术隔离(Meta 依然能访问),Confidential VM(年底上)才是密码学隔离(只有你有密钥)。目前只能信技术,想要真正的密码学保证,等 Confidential VM 上线再用敏感场景。

Q5: 为什么 Google Mariner 会砍掉?

A: 综合来看:①browser agent 战略方向错误(和 OpenAI/Anthropic/Microsoft 的桌面 agent 跑偏);②Chrome 生态是包袱不是资产;③团队被拆散去更高优先级项目;④capabilities 已经融入 Gemini Agent 兜底。这是战略转向,不是"能力不足"。

Q6: 独立开发者能做类似 Muse 的东西吗?

A: 完全可以。开源框架如 OpenClaw、LangGraph、CrewAI 都能搭 personal agent,而且天然就有 workspace 隔离(每个 agent 独立 workspace)。Meta 用 VM 做的事,开源社区用 workspace 隔离做了很久。关键差异是 Meta 有 30 亿用户的分发能力。

Q7: Apple Intelligence 什么时候能真正好用?

A: 我的判断是 iOS 27 前后(2027 年底 - 2028 年初)。App Intents 生态需要主流 app 大规模接入,Siri 的多步任务能力也需要模型升级。短期别指望,长期看好。
