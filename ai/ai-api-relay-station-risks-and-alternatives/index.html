AI API 中转站产业链拆解：4 种隐藏套路与自建替代方案

你在用 Cursor 或 Claude Code 写代码时，有没有想过把 base_url 换成一个中转站地址？

国内开发者调用 OpenAI、Anthropic、Google 的 API，面临两个硬门槛：网络不通和支付受限。中转站就是夹在中间的第三方服务——你给它人民币，它帮你转发请求到海外官方 API，再把结果回传给你。

听起来很美好。但这个行业的水，比你想象的要深得多。

TL;DR

  • 中转站产业链分四层：卡商→号池→中转站→用户，每层都在赚差价
  • 4 种常见套路：Token 暗税（虚报用量）、模型掉包（偷梁换柱）、缓存套利、数据收割
  • 17 家头部中转站中 15 家是个人运营，无企业注册、无 ICP 备案
  • 自建替代方案成熟：One API、Sub2API、LiteLLM 均可 Docker 一键部署
  • 有条件尽量用官方 API；实在要用中转站，选有企业资质的大平台

中转站是怎么运作的？

中转站的供应链可以拆成四层：

层级 角色 盈利方式
上游 卡商/号商 批量注册账号、倒卖虚拟信用卡
中游 号池 汇聚账号，批发 token 额度
下游 中转站 整合客户需求向上游压价，赚取差额
终端 你 付人民币，换 API 调用额度

这个链条的核心问题在于信息不对称。你不知道背后跑的是什么模型，不知道你的对话有没有被存档，不知道站长明天会不会消失。

V2EX 上有个帖子说得很直白：“开中转站很容易，一个 docker compose 就起了，难的是上游渠道和号池。“这意味着技术门槛不高，但渠道门槛极高——而渠道恰恰是黑活的重灾区。

4 种你必须知道的隐藏套路

套路一：Token 暗税滑块

你在代码里看到 usage.prompt_tokens: 150，但实际模型只消耗了 100 token。中转站在账单上乘以一个倍率（1.0x 到 3.0x），虚报你的用量。

这种套路最隐蔽，因为你在代码层面完全看不出来。你以为用了 100 token，账单上写 150，多付了 50% 的钱。

套路二：偷梁换柱

界面显示 claude-opus-4，后台跑的可能是某个 7B 开源模型。返回的 model 字段仍然显示你请求的原始模型名。

用量少的时候给你真货，高峰期或者流量大了悄悄切换。感觉模型今天"降智"了？很可能是真的。

套路三：Prompt 缓存吸血

AI 模型厂商对重复出现的内容（比如相同的 System Prompt）会给缓存优惠价。但中转站按原价收你的钱，把这部分差价默默吃掉了。

套路四：数据收割

有些中转站收集并贩卖用户的代码和敏感数据。你的代码、你的对话、你的 API Key，都可能成为别人的商品。

怎么选一家靠谱的中转站？

如果确实需要用中转站，以下是几个筛选标准：

1. 企业资质

有企业注册、有 ICP 备案的大平台优先。个人运营的中转站跑路风险极高——“低价+送额度 → 吸引用户 → 规模大了涨价降稳定性 → 群里一吐槽就封号踢人 → 某天域名消失，余额归零”，这是中转站跑路的标准生命周期。

2. 透明定价

价格公开、倍率明确、无隐藏收费。如果定价模糊或者倍率不透明，直接 pass。

3. 模型可验证

用复杂数学题或代码题测试模型效果，确认是否真的是宣传的模型。

4. 先小额测试

不管哪家中转站，先充 5-10 块钱试水。重点看响应速度、模型效果、是否真的是宣传的模型。

自建替代方案：开源 AI 网关对比

如果你有自己的海外服务器，自建 AI 网关是更安全的选择。以下是几个主流开源方案：

项目 语言 特点 适用场景
One API Go 24K+ Star，最流行，支持几十种模型 个人/小团队
New API Go One API 社区版，功能更丰富 个人/小团队
Sub2API Go 订阅转 API，支持拼车共享 有订阅账号的用户
LiteLLM Python 100+ 供应商，企业级 企业/团队
Higress AI Go CNCF Sandbox，生产级 企业/生产环境

自建方案的优势：

  • 完全可控：你知道背后跑的是什么模型
  • 数据安全：代码和对话不经过第三方
  • 成本透明：只付官方 API 费用 + 服务器费用

劣势：

  • 需要有自己的海外服务器
  • 需要一定的运维能力
  • 官方 API 仍需海外信用卡

我实测下来的账本

我对比了三种方案的成本（以 Claude Sonnet 4.5 为例，按 1M token 计算）：

方案 成本 优势 劣势
官方 API $3.00 最安全、最稳定 需要海外信用卡、网络不通
中转站 ¥15-25 支付宝付款、国内直连 模型可能掉包、数据风险
自建网关 ¥10-15 完全可控、数据自有 需要海外服务器、运维成本

注：中转站价格因平台和倍率不同差异较大，以上为常见区间。自建网关成本含服务器费用（约 ¥5-10/月）+ 官方 API 费用。

常见问题

Q1: 中转站能接 OpenClaw 吗？

A: 可以。OpenClaw 支持自定义 API 地址，把 base_url 改成中转站地址、api_key 换成中转站给的 Key 即可。但要注意中转站是否支持 OpenClaw 所需的全部接口。

Q2: 怎么检测中转站有没有偷换模型？

A: 用复杂数学题或代码题测试。如果模型在简单任务上表现正常但在复杂任务上明显降智，很可能是被换了。也可以用 Canary 验证 prompt——在对话中插入特定标记，检查返回是否一致。

Q3: 自建网关需要什么配置？

A: 最低 1 核 2G 内存即可运行 One API 或 New API。建议 2 核 2G 留余量。系统推荐 Ubuntu 24.04，Docker 一键部署。

Q4: 中转站的倍率是什么意思？

A: 倍率是中转站对 token 用量的放大系数。比如倍率 1.5x，你实际用 100 token，账单显示 150。倍率越高，实际成本越高。选择中转站时务必确认倍率。

Q5: 有没有完全免费的中转站？

A: 有些中转站提供免费额度（如 HyperAPI 在 V2EX 上给新用户补充 $15 额度），但免费额度通常有限，且来源不明的免费中转站数据风险更高。建议谨慎使用。

Q6: 企业团队应该选哪种方案？

A: 企业团队建议用 LiteLLM 或 Higress AI 自建，或者直接走官方 API（AWS、Vertex AI 等）。数据安全和合规性是企业的首要考虑。

Q7: 中转站会保存我的对话记录吗？

A: 可能会。中转站作为中间人，理论上可以记录所有经过的请求和响应。敏感代码和机密数据不建议通过中转站传输。
