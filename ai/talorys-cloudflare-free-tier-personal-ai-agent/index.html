你有没有想过，把一个 AI agent 完全跑在自己的 Cloudflare 账户里，不花一分钱？

Talorys 就是这样一个项目。MIT 许可，一条命令 npx create-talorys@latest 部署，支持聊天、记忆、任务、笔记、项目和定时提醒，无遥测、无分析、无广告。所有数据存在你自己的 Cloudflare 账户里，开发者看不到你的任何对话。

它在 Hacker News 上拿到了 209 分，发布两天就冲上了 Show HN。

TL;DR

  • Talorys 是单用户个人 AI agent，完全运行在 Cloudflare Workers + Durable Objects 上
  • 一条命令部署，无需服务器、数据库或第三方账户
  • 数据存储在单个 SQLite 支持的 Durable Object 中，开发者无法访问
  • 无遥测、无分析、无广告，隐私模型优于大多数商业 AI 助手
  • 专为 Workers Free 计划构建，但有每日请求限制，重度用户需付费

Talorys 是什么？

Talorys 是一个免费、开源的个人 AI 助手，完全运行在你自己的 Cloudflare 账户内。它的核心理念是：你的 AI agent，你的云。

功能覆盖：

  • 流式聊天：与 AI 实时对话
  • 记忆：记住你的个人事实，可查看和编辑
  • 任务管理：创建、跟踪、完成任务
  • 笔记和项目：组织你的想法和工作
  • 定时提醒：一次性或周期性提醒，每日任务摘要

单用户设计：安装时设置一个所有者密码，没有注册流程。

架构拆解：Cloudflare 上能跑什么？

Talorys 的架构完全基于 Cloudflare 开发者平台：

组件 技术 作用
前端 Vite + Pages Web UI 界面
后端 Workers (Hono) API 路由、业务逻辑
存储 Durable Objects (SQLite) 所有数据持久化
AI 推理 Workers AI 模型调用
定时任务 Cron Triggers 提醒、日常摘要

关键设计决策：

1. 单 Durable Object 存储

所有数据——聊天历史、记忆、任务、笔记——都存在一个名为 personal-agent 的 Durable Object 中。Durable Objects 是 Cloudflare 的有状态计算原语，结合了计算和存储，在 serverless 环境中构建有状态应用。

这意味着数据持久化不需要外部数据库，全部在 Cloudflare 网络内完成。

2. Workers Free 计划优化

Talorys 专为 Workers Free 计划构建。免费层提供：

  • 每天 100,000 次请求
  • 10ms CPU 时间/请求
  • 1GB 带宽/天

但 Workers AI 推理不在免费层内，需要绑定付费账户。不过 Cloudflare 提供每月 10,000 次免费推理请求，轻度使用足够。

3. 无遥测设计

Talorys 没有遥测、分析、跟踪或广告代码，不向开发者发送任何数据。这与大多数商业 AI 助手形成鲜明对比——你的对话只存在于你和 Cloudflare 之间。

与 OpenClaw / Claude Code 的关键区别

维度 Talorys OpenClaw Claude Code
定位 个人 AI 助手 通用 AI agent 框架 编程专用 agent
部署 Cloudflare 免费层 自托管/PVE/LXC 本地 CLI
数据控制 完全自有 完全自有 Anthropic 云端
成本 免费（轻度） 服务器费用 $20/月订阅
多用户 单用户 多用户/多 agent 单用户
编程能力 无 通过 Skills/MCP 扩展 原生代码编辑
提醒/任务 原生支持 需配置 无
隐私 无遥测 自托管可控 Anthropic 云端

Talorys 的独特价值：

  • 零成本启动：不需要服务器，不需要信用卡，Cloudflare 免费层即可运行
  • 隐私优先：无遥测设计，数据完全自有
  • 个人助手定位：不是编程工具，而是日常生活助手——任务、笔记、提醒

Talorys 的局限：

  • 无编程能力：不能写代码、不能执行命令
  • 单用户：不支持团队协作
  • 免费层限制：每天 100,000 次请求，重度用户需付费
  • 依赖 Cloudflare：如果 Cloudflare 出问题，你的 agent 也不可用

部署教程

前置要求

  • Cloudflare 账户（免费即可）
  • Node.js 18+
  • 一个域名（可选，但推荐）

一条命令部署 

npx create-talorys@latest

安装向导会引导你完成：

  1. 登录 Cloudflare 账户
  2. 创建 Workers 项目
  3. 配置 Durable Object
  4. 设置所有者密码
  5. 部署到 Cloudflare 网络

本地开发 

git clone https://github.com/rociiu/talorys
cd talorys
npm install
npm run dev

本地开发使用确定性 mock AI provider，无需 Cloudflare 登录即可体验全部功能。

安全模型

Talorys 的安全模型基于 Cloudflare 平台：

  • 数据隔离：每个用户的数据存储在自己的 Durable Object 中，物理隔离
  • 无遥测：开发者无法访问你的对话数据
  • 密码保护：单所有者密码，无注册流程
  • Cloudflare 基础设施：享受 Cloudflare 的 DDoS 防护、WAF 等安全能力

但要注意：Cloudflare 作为数据处理者，会处理你的聊天消息和记忆内容以运行 Workers AI 推理。审查 Cloudflare 的隐私政策和 Workers AI 条款。

常见问题

Q1: Talorys 和 OpenClaw 有什么区别？

A: Talorys 是个人 AI 助手，专注日常生活管理（任务、笔记、提醒）；OpenClaw 是通用 AI agent 框架，支持编程、多用户、多 agent。两者定位不同，可以互补。

Q2: 免费层真的够用吗？

A: 轻度使用（每天 50-100 次请求）完全够用。重度使用需要升级到 Workers Paid 计划（$5/月）。

Q3: 我的数据安全吗？

A: 数据存储在你自己的 Cloudflare 账户中，Talorys 开发者无法访问。但 Cloudflare 作为基础设施提供商，会处理你的数据以提供服务。

Q4: 支持哪些 AI 模型？

A: 通过 Workers AI 调用，支持 Cloudflare 提供的所有模型，包括 Llama、Mistral 等。

Q5: 可以自定义模型吗？

A: 目前不支持自定义模型。如果需要特定模型，可以考虑 OpenClaw 或其他自托管方案。

Q6: 支持 MCP 吗？

A: 不支持。Talorys 是个人助手，不是编程工具，不需要 MCP 协议。

Q7: 可以迁移数据吗？

A: 数据存储在 Durable Objects 中，可以通过 Cloudflare 导出。但迁移到其他平台需要自行开发适配层。
