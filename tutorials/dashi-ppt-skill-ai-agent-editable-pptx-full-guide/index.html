一个熟悉的场景：AI 帮我做了 PPT，但改不动

上周汇报，我把 8000 字的调研文档喂给某在线 AI 生 PPT 工具，10 秒钟出了 15 页。视觉花哨，图表齐全，看起来能交差。

真到自己修图、换字，噩梦开始了：

  • 页面是导出成图片的，一段小字都不能改，只能整页删掉重生成
  • 图表数据不能编辑，AI 编的数字跟原文对不上，只能自己截图外面画好再贴回去
  • 换主题？重新生成一次，之前改过的内容全丢
  • 想要 PPTX 版本？升级到年费 999 的会员才能导出，导出的还是一堆图片贴在 PPTX 里，一样改不动

那一晚我加班到两点，最后回到 Keynote 手搓。心里骂：AI 生 PPT 的产物如果不能改，就等于没生。

这周被同事塞了一个 GitHub 上 6.3k 星、评论区还挺乐观的 Skill：chuspeeism/dashi-ppt-skill。名字叫「大师 PPT」。看介绍很唬人：

一个真正适合职场人的 PPT Skill。把文档丢给你的 AI Agent，每一页都自带编辑控制台的 PPT Skill——不满意的地方直接在浏览器里改，改完还能一键导出成真实的、可编辑的 PPTX。

关键词就一个：改。每页自带控制台，能就地改字、换图、调布局、换配色，最后导出的是真的可编辑 PPTX——不是把网页截图塞进去那种。

抱着"又是 GitHub 上刷星刷出来的 AI PPT 项目"的心态，我在自己的 Codex 和 Claude Code 上装了一遍，用它生成 3 份真实的 PPT（一份融资复盘、一份行业研究、一份内部培训），跑通了导出。这篇写给同样被 AI 生 PPT 坑过的你。

它跟别的 AI 生 PPT 工具差在哪

先直接摆结论。市面上 AI 生 PPT 大致三类：

第一类：在线 SaaS（Gamma、AiPPT、闪击 PPT 一类）

  • 优点：3 秒出稿
  • 缺点：文本图片化、图表死板、改不动、导出要会员、内容要上传服务器

第二类：AI 生 Markdown / JSON，再走 pandoc / Slidev 转 PPTX

  • 优点：文本本身可编辑
  • 缺点：版式极简，不像正经 PPT，图表基本没有，需要自己熟 Markdown 语法

第三类：Agent Skill 直生 HTML/PPTX（dashi-ppt-skill 这一类）

  • 每页是 HTML + JS 组件，可以点开就地编辑
  • 图表、动画、控制台一起随包出稿
  • 命令行一键导出成真 PPTX，PPTX 里的文字进 PowerPoint 后仍然可编辑
  • 内容全程本地跑，文档不出机器

dashi-ppt-skill 就是第三类里目前星最多、版式最全的一个（12 套主题、1020 个版式页面）。

它的核心设计我总结成一句话：先生成一个能编辑的 HTML 版 PPT，改到满意再导出成 PPTX。中间的 HTML 就是你的编辑器。

这个思路比传统 AI 生 PPT 高明的地方在于——不是把编辑器丢给你去改 AI 的成品，而是把编辑能力直接编进每一页。每页右侧一个滑杆控制台，滑一下模块从 3 个变 5 个，点一下配色从蓝换绿，比 PowerPoint 手改还快。

环境准备（不到 3 分钟）

它是个 Skill，不是独立 App。你需要一个能读文件、写文件、跑 shell 的 AI Agent 作宿主。官方实测支持：

  • Claude Code（推荐，长文档处理稳）
  • Codex CLI（可以调用生图能力补图）
  • 豆包（需要启动办公模式）
  • Marvis / Workbuddy / Dumate / Qclaw（把 skill 文件放任意位置、读 SKILL.md 就行）
  • Cursor / 其他本地 Agent（需要文件读写 + shell 权限）

普通网页版 Chatbot（比如 ChatGPT 网页版）不行——生成器要跑本地 Node.js。

系统层面就两个硬要求：

  1. Node.js 20+ 和 npm
  2. Chrome / Chromium / Edge（导出 PPTX 和 PDF 时用来 headless 渲染）

Chrome 你机器上大概率已经有了。Node 版本用 node -v 检查一下：

node -v
# 想装或升级：
# macOS: brew install node@20
# Linux: nvm install 20 && nvm use 20
# Windows: winget install OpenJS.NodeJS.LTS

到这一步环境就齐了。

装：一条命令

打开你的 AI Agent（我这里以 Claude Code 举例），直接说：

帮我装 skill：npx dashi-ppt-skill@latest

Agent 会自动去跑这条命令。如果你在国内网络，让它加镜像：

npx --registry=https://registry.npmmirror.com dashi-ppt-skill@latest

我实测第一次装大约 90 秒，主要在拉 Puppeteer 相关依赖。之后每次跑同一条命令是"原地更新"，已装的依赖会保留。

装完的位置在你 Agent 的默认 skill 目录里。以 Claude Code 为例，通常在 ~/.claude/skills/dashi-ppt/ 下。你也可以让 Agent 帮你 ls 确认。

一次真实的 PPT 生成流程

我拿一份 6800 字的融资复盘文档当输入，实测下来 Agent 走了 5 个步骤，全程需要我做的只有回答几个问题。

第一步：给需求

我在 Claude Code 里丢文档，然后说：

用 dashi-ppt-skill 做一份 PPT。文档在 @funding-postmortem.md。受众是我们的董事会，篇幅控制在 15 页以内，重点讲教训和下一步。

Agent 读完文档，问了三个澄清问题：

  1. 想突出哪个结论？
  2. 是否要图表（比如漏斗、时间线）？
  3. 有没有指定风格倾向（专业感/活泼/暗色）？

回答完，进入第二步。

第二步：选主题

Skill 会在终端里丢出 12 套主题预览（用 Ascii 缩略 + 主题名称）：

  • theme01 轻拟态风、theme02 炫光紫绿风、theme03 深浅代码风
  • theme04 玻璃糖果风、theme05 色谱图表风、theme06 深色图谱风
  • theme07 冷白调研风、theme08 黑金实验风、theme09 深蓝杂志风
  • theme10 金色指数风、theme11 高能增长风、theme12 声波霓虹风

融资复盘我选了 theme07 冷白调研风——不出彩但董事会喜欢。

第三步：Agent 自动组稿

这一步全自动，Agent 会：

  1. 把长文档拆成 15 页的结构化字段（每页的角色是"封面/目录/指标/趋势/对比/流程/风险/结尾"等 20 种页面角色之一）
  2. 挑出对应版式（图表页会自动选到雷达图、瀑布图、漏斗图之一）
  3. 填充文案 + 预留图片占位符
  4. 启动本地预览服务

大概 3 分钟后，浏览器自动打开 http://localhost:xxxx，一份完整的 15 页 HTML 版 PPT 就出来了。

第四步：随手改

这一步是 dashi 的杀手锏。每一页的右侧都挂着一个控制台面板，最少 20 个可调维度：

  • 模块数量：滑杆一拖，页面里的 3 个数据卡片变 5 个（AI 自动重排布局）
  • 布局切换：下拉选"左图右文/上图下文/纯网格"等 5-8 种版式
  • 页面重点：改"数字优先/文字优先/图表优先"，页面重心自动重排
  • 配色：主题内预设 4-6 套配色，一键切换
  • 翻页动画：9 种切换动画随选

文字编辑：任意文本点一下就变成可编辑框，改完自动保存到本地文件。

图片替换：点击图片占位符，弹出选择框，拖拽本地图片进去即可。上传会自动压缩，我实测 5MB 的图变成 180KB。

我第 6 页的漏斗图 AI 编的数字不准（“注册转化 42%“实际是 38%），点开数字就地改成 38%，2 秒钟搞定。这在传统 AI 生 PPT 里几乎是不可能的。

改动全部自动保存，不用 Ctrl+S。

第五步：导出

改到满意，跟 Agent 说：

用 dashi-ppt-skill 导出这份 PPT 为 PPTX，输出到桌面。

Agent 会跑一个 headless Chrome，逐页把 HTML 转成 PowerPoint 原生节点。10 页大约 30 秒，15 页我这里跑了 48 秒。

产出文件我在 macOS 上用 Keynote 打开、Windows 上用 PowerPoint 2019 打开，文字都是可编辑的原生文本框，不是图片。图表在 Keynote 里显示为原生形状组合，可以继续调。字体如果本地没有，PowerPoint 会自动替换。

这是我最惊喜的一点——其他 AI PPT 工具导出的 PPTX 打开经常是"这一页是一张大图片”，dashi 这里是真的能改。

成本：一份 15 页 PPT 花了我多少 token

官方 README 说 10 页大约 10 万 token。我实测融资复盘 15 页，从组稿到定稿改了 3 轮：

阶段 Token 消耗
读文档 + 澄清问题 ~8k
组稿 + 生成 HTML ~85k
第 1 轮改（换主题） ~25k
第 2 轮改（重排 3 页） ~35k
第 3 轮改（调数据、换 4 张图） ~18k
导出 PPTX ~2k
合计 ~173k

用 Claude 3.5 Sonnet 大约 0.5 美元，用 GPT-4o mini 大约 0.15 美元。按 Codex 的 5 小时窗口额度算，一天生 5-6 份 PPT 不成问题。

如果你走 Claude Code 的 Max 订阅，基本零边际成本。

踩过的三个坑

坑 1：Node 版本不够，npx 报错

我的一台老 Mac 上 Node 是 18.19，跑 npx dashi-ppt-skill@latest 报 Unsupported engine。升级到 20 就好了。

brew unlink node && brew install node@20
brew link node@20 --force --overwrite

坑 2：Chrome 找不到，PPTX 导出失败

Linux 服务器上跑，报错 Failed to launch chrome。解决方案是显式指定路径：

export CHROME_PATH=/usr/bin/chromium

或者在 macOS 上：

export CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"

写进 shell rc 一次搞定。

坑 3：导出 PPTX 中文字体错位

Windows 上导出成 PPTX，打开发现"思源黑体"变成"宋体”。原因是导出用的是 headless Chrome 渲染，Chrome 里能看的字体到 PowerPoint 就没了。

解决：跟 Agent 说"用 macOS/Windows 系统自带字体（比如 PingFang SC / 微软雅黑）生成 PPT"，或者手动改 skill 目录下的字体配置。稳妥做法是主题选择时避开炫技字体（theme01/07/09 用系统字体较多）。

dashi vs 同类 Skill：什么时候用哪个

Skill 生态里生 PPT 的项目不止 dashi 一个。我按需求分类：

dashi-ppt-skill（6.3k 星）

  • 强项：可编辑度最高、版式最多（1020 个）、图表最全
  • 弱项：视觉相对"稳"，不适合追求极致视觉设计的场景
  • 适合：行业研究、融资复盘、竞品分析、内部汇报——要能改的稿子

codex-ppt-skill（5.3k 星）

  • 强项：走 GPT-Image-2 生图，页面视觉最新最艳
  • 弱项：改动难度更高（很多是生成后的图片元素）
  • 适合：新品发布、路演融资、封面海报——要好看多过要能改

ppt-master（4.7 万星）

  • 强项：走 python-pptx 直生原生 PPTX，跳过 HTML 中间态
  • 弱项：视觉相对朴素，编辑体验依赖 PowerPoint 本体
  • 适合：政务、事业单位、学术会议——产物必须是标准 PPTX

Mck-ppt-design-skill（麦肯锡风）

  • 强项：咨询公司扁平设计，70 个版式模式
  • 弱项：只有一种风格
  • 适合：咨询提案、战略报告——目标读者认这个视觉调性

我个人的选择顺序：日常汇报 → dashi、新品/融资路演 → codex、政务学术 → ppt-master。

什么场景不适合

Skill 再牛，也不是万能。以下场景我建议直接手搓：

  • 需要逐像素定制视觉（品牌年报、发布会 keynote）：Skill 的版式是模板化的，追求"一点儿都不能不一样"就别指望 AI
  • 超长 PPT 100+ 页：一次组稿的 token 消耗会翻好几倍，而且 Agent 上下文可能吃不下
  • 需要嵌 3D 模型、复杂动画：dashi 的翻页动画够用，但 PowerPoint 的 3D 变换、Morph 一类 dashi 导出的 PPTX 里没有
  • 老板明天要：装 + 试 + 熟练至少半小时，第一次上手不如 Keynote 手搓快

一个小观察：为什么 Skill 生 PPT 突然火了

GitHub 上"ai-ppt"话题下过去半年爆了。我数了下 dashi-ppt-skill 一个项目就有 20 多个类似的 fork/参考版本。这波兴起的时间点，恰好跟 Claude Code / Codex 把 Skill 机制做成一等公民对得上。

传统 AI 生 PPT 工具想给你一个"最终成品"，逻辑是输入 → 黑盒 → 输出。用户只能接受或整体重来。

Skill 的思路是给 Agent 一套工具 + 一套流程，让 Agent 一步步跟你协作。用户在过程中就能干预，产物本身也是"可协作物"——HTML + 控制台。这种交互方式，比"AI 一次给你一个成品"更接近人的正常工作流。

我猜未来 6 个月，你会看到更多类似的 Skill 涌出来——PDF 处理、数据分析、图表设计——本质都是把生成过程本身开放给用户编辑。

快速回顾

  • 装：npx dashi-ppt-skill@latest（国内加 npmmirror 镜像）
  • 环境：Node 20+ 和 Chrome/Chromium/Edge
  • 用：AI Agent 里说"用 dashi-ppt-skill 做 PPT"，丢文档，选主题
  • 编辑：每页右侧控制台，滑杆调布局、点击改文字、拖拽换图
  • 导出：说一句"导出成 PPTX"，headless Chrome 转真原生 PPTX
  • 成本：一份 15 页 PPT 约 15-18 万 token
  • 定位：要能改的稿子，不是要最炫的稿子

如果你也被 AI 生 PPT 的"改不动"折磨过，这一个周末的实测给我的最大心得是：Agent Skill 这条路正在把 AI 生成物从"成品"变成"工作台"。 而 dashi-ppt-skill 就是目前把这个理念落地得最完整的一个 PPT Skill。

值得装一个试试。反正 npx 一句话，用不上删掉也不留痕迹。
