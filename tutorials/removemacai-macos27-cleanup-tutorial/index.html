升级到 macOS 27 后，你的 Mac 硬盘是不是突然少了十几个 GB？

这不是你的错觉。macOS 27 Golden Gate 做了一个让很多用户不满的改变：Apple Intelligence 变成了强制集成。系统不再提供统一的关闭开关，模型会自动下载，即使用户逐一关闭相关功能，基础模型仍会残留在磁盘上。

苹果官方数据显示约需 12-14GB 空间，但实际观察中，部分设备占用超过 30GB，甚至有 MacBook Air 用户报告占用高达 35GB。对于 256GB 存储的 Mac 用户来说，这相当于损失了 10% 以上的可用空间。

开发者 Om Lahore 看不下去了，做了一个开源命令行工具 RemoveMacAI，一键解决这个问题。

TL;DR

  • macOS 27 移除了 Apple Intelligence 总开关，模型自动下载且无法彻底删除
  • RemoveMacAI 通过配置描述文件重定向模型下载到本地黑洞，阻止重新下载
  • 全程不关 SIP、不修改 /System 目录、不联网、不收集数据
  • 支持 --keep 白名单保留特定功能（如照片消除笔）
  • 一条命令 removemacai revert 即可完全恢复

为什么 macOS 27 的 AI 模型这么难删？

在 macOS 26 及之前，用户可以通过一个统一的开关关闭 Apple Intelligence。但在 macOS 27 Golden Gate 中，苹果移除了这个总开关，将设置分散到"设置"和"屏幕使用时间"中十几个选项里。

更关键的是，即使你逐一关闭所有功能，基础模型仍然会保留在磁盘上。这些模型文件位于系统深处，普通用户无法直接删除。

macOS 27 还强制要求使用 Apple Silicon 芯片，并将 Apple Intelligence 设为默认行为。这意味着所有 M 系列芯片的 Mac 都会自动下载这些模型。

RemoveMacAI 是什么？

RemoveMacAI 是一款专为 macOS 27 设计的开源命令行工具，由开发者 Om Lahore 开发。它的核心功能：

  • 禁用 Siri AI、写作工具、Genmoji、图像游乐场、ChatGPT 扩展
  • 关闭邮件、信息、Safari 和备忘录中的摘要、智能回复
  • 删除基础模型文件，释放 10-12GB 磁盘空间
  • 通过配置描述文件阻止模型重新下载

GitHub 上已获得超过 1,700 个 Star，Reddit 用户反馈运行有效。

安装 RemoveMacAI

前置要求

  • Apple Silicon Mac（M1 及以上）
  • macOS 27.0.1 及以上版本
  • 终端（Terminal）

方式一：curl 一键安装 

curl -fsSL https://raw.githubusercontent.com/om-lahore/RemoveMacAI/main/install.sh | bash

方式二：Homebrew 安装 

brew install removemacai

安装完成后，终端中输入 removemacai 即可使用。

使用教程

第一步：查看当前状态 

removemacai status

这会显示当前 Apple Intelligence 各功能的开启状态，以及模型文件占用的磁盘空间。

第二步：预览更改（可选） 

removemacai off --dry-run

试运行模式，预览将要关闭的功能和删除的文件，不做实际修改。

第三步：执行关闭 

removemacai off

系统会打开"设置"窗口，提示你批准配置文件。批准后，工具会：

  1. 安装配置描述文件，将模型下载重定向到本地封闭端口
  2. 通过苹果官方资产服务删除模型文件
  3. 禁用所有 AI 功能

第四步：验证结果 

removemacai status

确认所有功能已关闭，磁盘空间已释放。

保留特定功能：–keep 白名单

如果你不想关闭所有功能，可以使用 --keep 参数保留特定功能：

removemacai off --keep photos_cleanup

这会保留照片消除笔（Photos Clean Up）功能，同时关闭其他所有 AI 功能。

目前支持的白名单选项包括：

选项 功能
photos_cleanup 照片消除笔
spatial_photos 空间照片
visual_intelligence 视觉智能

恢复默认设置

如果将来想重新启用 Apple Intelligence，一条命令即可恢复：

removemacai revert

这会移除配置描述文件，恢复所有设置。macOS 会在需要时重新下载模型。

技术原理

RemoveMacAI 的巧妙之处在于它不直接修改系统文件，而是利用苹果自身的管理机制：

  1. 配置描述文件：安装一个配置文件，将模型下载尝试重定向至封闭的本地端口，macOS 无法再次下载模型
  2. 资产服务删除：通过苹果官方的资产管理服务删除模型文件，无需直接操作 /System 目录
  3. 限制键禁用：应用苹果自身的限制键（restriction keys）禁用各项 AI 功能

由于未直接修改 /System 目录，系统完整性保护（SIP）保持启用状态，系统安全沙箱不受影响。

注意事项

  • 兼容性：部分限制键已在 macOS 26.4 中被弃用，尽管目前在 27.0.1 中仍有效，但长期兼容性无法保证
  • 未来更新：未来的 macOS 更新可能会破坏这一机制，建议关注项目更新
  • 语音听写：因使用独立设置，不受 RemoveMacAI 影响
  • 网络请求：工具不发起任何网络请求，不收集任何数据

常见问题

Q1: RemoveMacAI 安全吗？会不会影响系统稳定性？

A: 安全。工具不修改 /System 目录，不关闭 SIP，不发起网络请求。所有操作都通过苹果官方机制实现，且完全可逆。

Q2: 释放的空间有多少？

A: 官方数据约 12-14GB，实际观察中部分设备可释放 30GB 以上，具体取决于已下载的模型数量。

Q3: 关闭后会影响 Mac 正常使用吗？

A: 不会。关闭的只是 Apple Intelligence 相关功能，系统其他功能完全正常。语音听写因使用独立设置也不受影响。

Q4: 如果将来想重新启用怎么办？

A: 执行 removemacai revert 即可移除配置描述文件，恢复所有设置。macOS 会在需要时重新下载模型。

Q5: 支持 Intel Mac 吗？

A: 不支持。macOS 27 Golden Gate 强制要求 Apple Silicon 芯片，Intel Mac 无法升级到 macOS 27。

Q6: 工具会收集我的数据吗？

A: 不会。工具不发起任何网络请求，不收集任何数据，所有操作都在本地完成。

Q7: 为什么苹果要强制集成 Apple Intelligence？

A: 苹果目前的重心是跨设备和语言扩展 Intelligence 功能。尽管在宣传中将模型定位为可选功能，但操作系统层面的设计趋向强制集成。RemoveMacAI 为个人用户提供了类似企业 MDM 的管理能力，恢复了用户对硬件控制权的选择。
