微软偷偷给 Win11 塞了个会扫脸的照片 App，还卸不掉 —— 手动清除全流程

打开开始菜单，你会看到一个自己从没装过的图标：OneDrive Photos。

不是错觉。是微软 2026 年 7 月底开始，通过 Windows Update 和 OneDrive 客户端更新，静默推送的一个"新"照片应用。没弹窗、没变更日志、没同意提示。图标就那么出现了。

更离谱的是，你卸不掉它。

微软到底干了啥

先说事实。这不是一个传统意义上的 UWP/MSIX 应用，Microsoft Store 里找不到，「已安装的应用」里也没有独立条目。

它藏在这里：

C:\Program Files\Microsoft OneDrive\OneDrive.App.exe

底层是 WebView2，也就是网页套壳。OneDrive 同步客户端每次更新，把这个 exe 一起塞进去，然后在开始菜单丢一个快捷方式。

Windows Latest 7 月 29 日的实测证实了一件更恶心的事：即使你没登录任何 Microsoft 账号，OneDrive Photos 打开就能直接读取你本地硬盘里的照片，还给你分门别类展示。人脸分组功能默认关，但初次打开会弹窗劝你开启。

微软 8 月初回应了。原话大意：「OneDrive Photos 是一次孵化中的新体验，推广范围超出了预期。」翻译一下：本来只想给消费者版慢慢试，结果一激动把企业版电脑也一起装了。

企业管理员的原话更实在：

我们用 Intune 管着数百台电脑，一觉醒来所有电脑开始菜单里都多了个 OneDrive Photos。这个应用连 Entra 账户都不兼容。不彻底卸载 OneDrive 就删不掉它。

为啥卸不掉

因为它不是独立应用。

传统的 UWP 应用你可以 Get-AppxPackage | Remove-AppxPackage。传统 Win32 应用能在「设置 → 已安装的应用」找到卸载按钮。OneDrive Photos 都不属于这两种。

它是 OneDrive 同步客户端内部的一个组件。共用一套安装目录、共用一套更新通道、共用一套自动修复机制。

Windows Latest 后来又补了一刀：即便你手动删了快捷方式和 exe，只要 OneDrive 还活着，下次同步客户端更新就会把它重新塞回来。

这不是 bug。这是设计。

三种清除方案

按"手起刀落"程度从轻到重排。

方案 A：只删快捷方式（保 OneDrive）

如果你还在用 OneDrive 同步，只是不想在开始菜单看到那个图标，删快捷方式够了。

管理员 PowerShell 里跑：

$shortcut = "OneDrive Photos.lnk"
$paths = @(
  (Join-Path $env:ProgramData "Microsoft\Windows\Start Menu\Programs\$shortcut"),
  (Join-Path $env:PUBLIC "Desktop\$shortcut")
)
Get-ChildItem "C:\Users" -Directory | ForEach-Object {
  $paths += Join-Path $_.FullName "AppData\Roaming\Microsoft\Windows\Start Menu\Programs\$shortcut"
}
foreach ($p in $paths) {
  if (Test-Path -LiteralPath $p) {
    Remove-Item -LiteralPath $p -Force
    Write-Host "Removed: $p"
  }
}

代价：OneDrive 下次自动更新（一般几周一次）后，快捷方式会回来。你得把上面这段脚本挂到计划任务里，每次 OneDrive 更新完自动跑一遍。

治标不治本，但对多数人够用。

方案 B：连 OneDrive 一起卸掉（最彻底）

这是微软官方目前唯一支持的方式。

  1. 打开 设置 → 应用 → 已安装的应用
  2. 搜索 Microsoft OneDrive
  3. 点右侧三点 → 卸载
  4. 重启一次

重启后开始菜单里 OneDrive Photos 会跟着消失。以后 Windows Update 也不会再推它。

代价：你彻底没了 OneDrive 云同步。如果你本来就是 Google Drive / 坚果云 / 本地 NAS 用户，OneDrive 只是 Windows 硬塞的赠品，这方案是干净利落的一刀。

如果你在用 Microsoft 365、Office 文档要跨设备，那这刀砍下去代价有点大。

方案 C：Intune 远程清理（企业管理员）

大规模场景请走 Intune 远程修复脚本，System Center Dudes 有一份现成的可以参考。核心逻辑还是"找快捷方式 + 删除 + 日志"，配上 Intune 的计划任务重跑机制。

普通个人用户不用管这个。

我怎么选的

我的两台 Windows 电脑一台工作一台游戏。工作机走的是坚果云 + Git，OneDrive 从来没登录过 —— 直接 方案 B，卸载 OneDrive，一键清干净，重启完连 OneDrive 图标都不见了，桌面清爽。

游戏机绑着 Microsoft 账号还有几个订阅，OneDrive 得留着。走 方案 A，加了一个每月自动清理的计划任务：

schtasks /Create /SC MONTHLY /TN "Remove OneDrive Photos Shortcut" ^
  /TR "powershell.exe -ExecutionPolicy Bypass -File C:\Scripts\clean-onedrive-photos.ps1" ^
  /RU SYSTEM

丑陋，但能跑。

微软那句"正在修复"值得等吗

微软自己说了两件事：

  1. 企业版 PC 上安装的 OneDrive Photos 会自动删除（8 月中旬起陆续推送）
  2. 正在开发独立卸载控件，让用户能分开卸 OneDrive 和 OneDrive Photos

第一件事 IT 管理员可能能等到。第二件事没有明确时间表 —— 微软说"正在开发"的东西，你懂的。

如果你今天就想桌面干净，别等。上面三种方案挑一个，动手。

一句话总结

微软把 OneDrive Photos 当"OneDrive 的一部分"来分发，就是想让你想删它的时候得掂量一下"我还要不要 OneDrive"。

这个套路以前叫捆绑安装，我们骂了流氓软件二十年。今天，操作系统本身来干这个。
