Windows 装机别乱下工具了：tubatools 把硬件检测、装系统、清垃圾、跑分装进一个箱子

每次给家人装 Windows，或者帮朋友验二手主机，我都得挨个找 CPU-Z、AIDA64、FurMark、CrystalDiskMark、Ventoy、Dism++。找完一遍，下载页广告比软件还多，还容易误装个全家桶。图吧工具箱 WinUI3 版（tubatools）就是为了解决这件事：GPL-3.0 开源，用 WinUI 3 + .NET 10 重新做了个绿色便携版，把硬件检测、装机助手、网络诊断、垃圾清理、性能跑分 70 多个工具塞进一个箱子。

TL;DR

  • tubatools 是图吧工具箱的 WinUI 3 重构版，GPL-3.0 开源，x64/x86/ARM64 全支持，Windows 10 1809+ 可用
  • 70+ 工具分 9 类：处理器 9、显卡 11、显示器 3、内存 7、硬盘 20、烤鸡 2、综合检测 5、外设 7、其他 19，开箱即搜即用
  • v1.6.1 起 Lite 版内置 CPU-Z/GPU-Z/HWiNFO/FurMark 最小内核，首次启动快；完整 Tools.zip 才下全部 70 多个工具
  • 跑分支持云同步、最多 6 份历史报告对比，雷达图/柱状图/表格三种视图，验二手主机时很好用
  • 冷门但有用的点：防晕 3D 准星、硬件信息页自动检测 CPU/GPU 品牌换品牌壁纸、商店版可先下 Lite 再升级完整内核

为什么你装机时总要下 10 个杂毛软件？

验机、装系统、清垃圾、看配置，每个动作背后都是一个独立软件。CPU 要看 CPU-Z，烤机要 FurMark，硬盘要 CrystalDiskMark，装系统要 Ventoy，清垃圾要 Dism++，跑分要 AIDA64。每个工具单独下，下载页里夹带捆绑的概率随广告位数量上升。你刚装完系统，桌面就多 3 个全家桶。

传统图吧工具箱解决了这个问题，但它是 Delphi 写的，老、闭源、乱码、高 DPI 模糊。tubatools 把它重做成 WinUI 3 + .NET 10，保留“一个箱子装所有工具”的思路，同时解决 3 个老版本痛点：

  • 界面：矢量渲染，高 DPI 不糊
  • 乱码：原生 UTF-8，任意区域设置下中文正常
  • 绿色：ZIP 便携版，解压即用，用完删掉不留痕

注意“硬件检测”里的性能跑分不是单一工具。它做完整套测试（CPU/GPU/内存/硬盘/浏览器），按比例算游戏分和办公分，导出 PDF 报告，还带“历史对比”窗口：点时间线看任意一次成绩，跟上次自动比涨跌。验二手主机时，我跑完第一次，让对方复跑一次，两报告一对，缩水没缩水一目了然。

下载哪种版本？Lite、完整版、商店版怎么选

v1.6.1 起官方给三种入口，别乱下：

版本 文件 适用 启动体验
便携完整版 TubaWinUi3_Portable_x64.zip 直接 U 盘带走验机，解压即用 含全部 70+ 工具，首次稍重
便携 Lite 版 TubaWinUi3_Lite_x64.zip 第一次装系统、网络差、怕大包 内置 CPU-Z/GPU-Z/HWiNFO/FurMark 最小内核，可在设置里升级完整内核
安装版 TubaWinUi3_Setup_x64.exe 固定办公机常驻 传统 Inno Setup 安装
商店版 Microsoft Store 9p15095x7mgb 不折腾、自动更新 首次可先下 Lite 工具包，再选下完整 Tools.zip

我一般随身带 Lite 版。验机时 CPU-Z + HWiNFO + FurMark 已经覆盖 90% 场景。要跑完整 70 个工具才升级 Tools.zip。官方仓库开头就有警告：近期很多非官方下载渠道，只认 GitHub Releases 或 Microsoft Store，别从第三方下载站下，容易夹带。

几个冷门但很顶的功能

不吹“检测 CPU”这种常规功能。tubatools 里有几个设计点，是老工具箱做不到的：

  • 硬件信息页自动认硬件品牌换壁纸：启动时检测你的 CPU/GPU 品牌，自动下专属品牌壁纸做背景。不需要可设置关闭。验机时一边看配置一边看背景，心理暗示拉满。
  • 硬件信息“戏称模式”：点一下“硬件信息”标题，各硬件名会变成趣味戏称（网络梗），再点恢复。纯娱乐，但装机现场活跃气氛真好用。
  • 防晕 3D 辅助器：全屏游戏可开准星覆盖层，强制置顶不受窗口模式影响；开“精简模式”后主窗口可最小化，只留准星，内存占用降到极低。给晕 3D 的朋友调屏幕准星比硬扛好。
  • 跑分云同步：结果可上传 GitHub/GitCode 双源，断网时切另一个源。本地历史最多 6 份对比，雷达图/柱状图/表格。
  • Office 文档转 PDF：v1.6.1 接入 OfficeCLI 渲染引擎，约 33MB 一次性下载后离线用，保留排版/表格/页眉页脚，不装就回退内置引擎。装完系统常要转文档，顺路解决。
  • 下载中心多线程：多个工具并行下，不再一个接一个排队。弱网装机场景体感差很大。

实测体感（Win11 x64 + i5/R5 级别办公本）

我按验机场景实际跑了一遍，记录的是主观体感加粗略数字，不是精确 benchmark：

  • 启动：Lite 版冷启动到可点选约 2-3 秒；完整便携版因预加载工具清单，首次约 4-6 秒，v1.1.5 后做了硬件信息预加载，首开“硬件信息”页等待明显缩短。
  • 内存：主界面常驻约 80-150MB，跑分 + 烤机同时开 FurMark 才见顶（取决于 GPU）。开“快速模式”禁用所有界面动画后，低配机上切换更顺。
  • 磁盘占用：Lite 包解压后几十 MB，完整 Tools.zip 解压后数 GB 量级（含 70+ 工具内核）。验机 U 盘建议留 8GB 以上。
  • 跑分耗时：完整套（CPU/GPU/内存/硬盘/浏览器）约 10-20 分钟，FurMark 烤鸡段最久。
  • 高 DPI/乱码：150% 缩放下界面矢量渲染正常，中文无乱码（这是相对老 Delphi 版的主要改进）。
  • ARM64：官方支持 Snapdragon 等原生 ARM64，我没法在 x86 机器上复测，按 release 标注为准。

数字仅供参考。你机器配置不同会差，但量级关系成立：Lite 快、完整重、快速模式省。

和老图吧工具箱、其他清理工具比，什么该选它

维度 老图吧工具箱（Delphi，tbtool.cn） tubatools（WinUI3，本文） Dism++ / 单点清理工具
开源 源码可下但旧 GPL-3.0 明确 部分开源
架构 WinForms，老 WinUI 3 + .NET 10 视工具
工具数 类似 70+ 70+，分类更清晰 单点功能
高 DPI 模糊 矢量正常 视工具
便携 压缩包 ZIP 便携 / Lite 首启快 视工具
场景 装系统 + 检测 装机 + 检测 + 清理 + 跑分 + 云同步 只清垃圾/只删注册表

结论：要“一个箱子管装机到验机全流程”，选 tubatools。只想清一次垃圾，单点 Dism++ 更轻。 老版本还在用且没高 DPI 痛点的，不用急迁移；但新装系统、验二手、给家里老人配机，新版值得一步到位。

常见问题

Q1: tubatools 是图吧工具箱吗？和 tbtool.cn 那个什么关系？

A: 是的。tubatools（TubaWinUi3）是图吧工具箱的重构开源版，WinUI 3 + .NET 10。tbtool.cn 上的老版本（Delphi）仍在维护，两者是同一品牌新旧两套，新版功能更全、界面现代。认准 GitHub luolangaga/tubatools 或 Microsoft Store，别下第三方站。

Q2: 一定要联网才能用吗？

A: 不是。解压便携版即可离线跑全部内置工具。跑分云同步、Office 转换引擎、完整 Tools.zip 下载才要联网；断网时跑分可切 GitCode 源，不联网就只用本地历史。

Q3: 它会不会偷偷改注册表、写敏感目录？

A: 官方声明“无捆绑强制安装，不写入注册表，没有任何敏感目录及文件操作”。GPL-3.0 源码可查。涉及 Windows 激活（KMS）、硬件伪装这类项，是用户主动点开才执行，默认不动。

Q4: 笔记本内存小，跑完整 70 个工具卡不卡？

A: 主界面 + Lite 内核在 8GB 内存机上流畅。完整 Tools.zip 会多占磁盘，不是常驻内存。开“快速模式”禁动画，低配机体感更好。烤机 FurMark 是 GPU/CPU 满载，正常发热别误以为卡死。

Q5: 跑分报告能给别人看吗？验二手主机够用吗？

A: 够。导出 PDF 专业报告，含 CPU/GPU/内存/硬盘/浏览器分项，历史对比窗口可并排两份报告看涨跌。验机时先跑一次留底，对方复跑一次对比，缩水/虚标直接可见。再配合 CPU-Z、HWiNFO 看具体频率、时序、温度，基本不踩坑。

Q6: 我只有 32 位老机器，能装吗？

A: 官方兼容表：x86（32 位）完全支持，Windows 10 1809+ 起。下 TubaWinUi3_Setup_x86.exe 或对应便携版即可。ARM64 原生支持（骁龙等）。

Q7: 和 AIDA64 单用比，它跑分靠谱吗？

A: 它把 AIDA64 作为内置工具之一，跑分是综合 CPU/GPU/内存/硬盘/浏览器按权重算的分数，不是 AIDA64 单一 Score。要看某项细节就单独开 AIDA64/HWiNFO；要一张总账加历史对比，用它的综合跑分更省事。
