CleanMyMac 199 刀能干的事，这个开源 MangoDisk 免费全给你（macOS + Windows 双平台）

先讲个真实故事。

我 Mac 的 512GB SSD 用了两年，前几天点开「关于本机 → 存储」，系统那一栏红彤彤地写着 187GB。我确信我没装过 187GB 的系统文件。翻遍了 ~/Library/Caches、~/Developer、.docker、.gradle、Xcode DerivedData——最后累到想直接掏钱买 CleanMyMac。

打开官网一看，$149.95/年，或者 $199.95 买断（还得升级付费）。199 刀，够我买两包咖啡豆用一整年了。

于是我又去搜有没有免费替代。这一搜，就撞见了昨天在阮一峰 Weekly 上被作者自荐的 MangoDisk（芒果磁盘清理）——GPL-3.0 开源、macOS + Windows 双平台通吃、Tauri 2 + Rust 内核、界面颜值在线，Trendshift 上 Rust 榜进过日榜前 11。

装完试了两小时，我基本可以说：这就是 CleanMyMac 的免费替代品，而且 Windows 用户第一次有了对得起颜值的选项。

项目地址：https://github.com/harry0703/MangoDisk 官网：https://mangodisk.app

为什么值得一试

先说结论，不绕弯。MangoDisk 在这三个维度赢：

1. 双平台，尤其救 Windows 用户。 macOS 有 CleanMyMac、DaisyDisk、OmniDiskSweeper，就算免费也有 Dusty、GrandPerspective。Windows 这边呢？CCleaner 被 Avast 收购之后各种全家桶弹窗，WinDirStat 十几年没大更新界面像 XP，BleachBit 又太糙。MangoDisk 一套 UI 同时跑 macOS 和 Windows，Windows 用户终于不用在难看和不安全之间二选一。

2. 免费开源 + 不用登录 + 不联网。 GPL-3.0，源码在 GitHub 全公开，规则库也公开在仓库里可审计。打开就用，不注册、不弹窗、不推服务。对付费软件那种「先扫描后收钱、订阅到期就变砖」的套路免疫。

3. 技术栈选得聪明。 Tauri 2 + Rust + Vue 3。Rust 负责扫描和文件系统操作，扫得快、内存占用低；Tauri 打包体积远小于 Electron，冷启动秒开；Vue 3 拿来堆 UI，视觉效果不输原生 App。作者宣传的对比数据是「同硬盘同目录，MangoDisk 20.6s vs 其他工具 26.5s」——不算特别夸张，但至少不慢。

它到底能干嘛

官方分了五个模块，我挨个说人话讲。

深度清理。 一次扫描系统缓存、浏览器缓存、临时文件、应用卸载残留。对开发者更狠：能识别 node_modules、Rust target/、Gradle 缓存、Xcode DerivedData、Python 虚拟环境、.NET 构建产物，以及本地跑的 Ollama、HuggingFace、llama.cpp 模型缓存。我 Mac 上一次性扫出 41GB 的开发垃圾——node_modules 占了 18GB，Xcode 12GB。

大文件清理。 扫全盘或指定文件夹，按类型和大小筛。这个功能其实 macOS 自带存储管理里就有，但 MangoDisk 的分类粒度和排序更顺手。

重复文件清理。 用内容哈希对比，不靠文件名——这个才是重点。文件名相同但内容不同的、或者内容相同但文件名不同的（比如 IMG_1234.jpg 和 IMG_1234 副本.jpg 和 IMG_1234-2.jpg），都能正确识别。而且智能选择会保证每一组至少留一份，不会手滑全删。

应用卸载 + 残留清理。 卸载应用时同步扫 ~/Library/Application Support、~/Library/Preferences、~/Library/Caches 里的对应目录，避免 App 拖走了但配置文件、日志、缓存还在占 3-5GB 的情况。这块 Windows 上更有价值——大家都知道 Windows 的卸载有多脏。

磁盘空间分析（矩形图）。 就是常说的 TreeMap，用色块面积表示占用大小，颜色区分类型，能一层层钻进目录。这功能 macOS 上有 DaisyDisk（29.99 刀），Windows 上有 WinDirStat（免费但丑），MangoDisk 把它做进了同一个界面。

安装

macOS 最省事的是 Homebrew：

brew install --cask harry0703/tap/mangodisk

不用 Homebrew 也行，去 GitHub Releases 或者 https://mangodisk.app 下 DMG，拖到「应用程序」文件夹。

Windows 更直接，Releases 下 .exe 安装包，双击下一步下一步。

对了，还有 CLI：mangodisk 是桌面应用的命令行入口，从源码构建 CLI 后能跑扫描、清理、JSON 输出。适合塞进定时任务或 CI 脚本里做机器巡检，不过日常桌面用户不用管这个。

规则库怎么保证不误删

清理工具最怕什么？误删配置、误删数据。作者在这一块的设计我看了 README，态度挺认真：

MangoDisk 维护自己的跨平台清理规则库，不直接照搬第三方项目。Windows 规则会参考 Winapp2.ini（就是 CCleaner 那套开源规则集），但仅作为「研究线索」——每一条规则要进正式版本，必须做三项审查：

  1. 来源核对：路径用途和数据归属，去 Microsoft、Apple、软件厂商官方资料确认
  2. 边界确认：判断能不能安全重建，排除个人文件、应用私有数据、系统保护路径
  3. 实机验证：在真机 macOS 或 Windows 环境跑一遍，验证路径正确、清理结果和异常场景

规则库全部在仓库里公开，修改记录可审计。执行清理前还会把内容列出来让你确认。

这种「先审后做」的态度在国产开源清理工具里不多见——大部分同类项目都是把 Winapp2.ini 一把梭全塞进去，出了问题再改。安全边界这个事，我愿意为它多花一分钟等待。

我踩过的一个坑

有个细节新用户容易忽略——首次扫描「深度清理」时，如果你装了本地 AI 模型（Ollama、LM Studio、ComfyUI），扫描结果里会出现「AI 模型缓存」条目，动辄十几 GB。

这些不是垃圾。 是你花时间和带宽拉下来的模型权重，删了下次还得重新下。MangoDisk 会把它们单独归类，默认不勾选，但如果你手贱全选删除按钮，就得从 HuggingFace 重新拉一次 deepseek-r1-70b 的 40GB 权重。我第一次差点手滑。

好在清理执行前有二次确认，勾选项一列一列写清楚。养成「看一眼再点确认」的习惯即可。

局限 & 谁不适合

诚实一点，说说它的短板：

  • 移动设备不管。 只清桌面机磁盘，iOS/Android 数据线里那些相机胶卷、微信缓存管不了。
  • 不做实时监控。 不像有些付费软件常驻后台随时清。MangoDisk 是主动扫描型，你得自己想起来点一下。
  • 规则库还在成长。 371 star（截至 08-22）算是新项目，某些冷门国产软件的残留路径可能识别不到。遇到没扫到的，欢迎去 GitHub 提 issue。
  • 中国大陆下载可能慢。 GitHub Releases 走的是海外 CDN，网差的话建议开代理或者去官网找镜像。

如果你是「电脑硬盘永远 90% 满、但不想学命令行、又不想花钱买软件」的那类用户——MangoDisk 就是给你写的。
