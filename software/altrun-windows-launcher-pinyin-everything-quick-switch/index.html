ALTRun：不到 1MB 的启动器，凭什么把 Everything、Listary、剪贴板历史塞进一个窗口

按 Alt+Space，敲三个字母，回车——程序开了。就这么点需求，Windows 上却挤着至少四个名字：Wox、uTools、Listary、ALTRun。前三个我都用了超过一年，最后一个是我上周才从「小众软件」挖到的：一个 2013 年就开始写、中间沉寂、2023 年用 AutoHotkey v2 推倒重来的项目。

TL;DR

  • ALTRun 安装包约 1.4 MB（v2026.11.16），解压即用，不装 .NET / Electron，不写注册表。
  • 拼音首字母是中文场景杀手锏：wx 出微信，jsb 出记事本，文件同理（cs → 测试文件.zip）。
  • 装了 Everything 就白嫖它的索引，没装则走内置索引；实测数据见下方表格。
  • Quick Switch 直接把打开/保存对话框跳到 Total Commander / Directory Opus / 资源管理器的当前目录，这是 Listary 的老绝活。
  • 它是 GPL-3.0 真开源，作者一人维护，每个 PR 在 Windows 上自动跑 8,000+ 项测试。

先说清楚：它和那三位不是一个物种

很多人搜到 ALTRun，第一反应是「又一个 Wox 模仿」。我一开始也这么想，直到把四个都摆在一起看内存占用。

维度 ALTRun Wox (2026 版) uTools Listary
语言 / 内核 AutoHotkey v2 Go（全原生 GPU 渲染） TypeScript / Electron 系 C++（内嵌 Everything）
GitHub Star ~350 ~27,700 ~20,000+（主站分发） 无公开主仓库
体积 / 内存量级 最小一档（MB 级） 官方称日常 ~150 MB 常驻 中（Electron 系） 轻量，但 Pro $24.95
中文支持 拼音首字母 + 简繁界面 一般，需插件 好 继承 Everything
插件生态 脚本（.ahk/.ps1/.bat/.py） Node/Python/脚本插件市场 中文插件市场最活跃 少
许可证 GPL-3.0 GPL-3.0 闭源免费 免费 + Pro 收费

注：Wox 数据来自其官方 README（Latest: v2.5.0 · Nov 2026）；Star 数为 2026-11-19 GitHub API 抓取，未独立核实更多版本细节。

看出问题了吗？Wox 赢在生态和跨平台，uTools 赢在插件市场，Listary 赢在文件管理深度。ALTRun 赢在「小」和「中文」。

如果你要的是「一个能搜到东西的框」，三者都行。但如果你是中文用户、机器配置一般、又受够了 Electron 常驻吃内存，ALTRun 的存在感会突然变强。

它到底有多小？

先看硬数据。官方 README 说「约 2.5 MB」，而最新发布包实测更小：

  • Release：v2026.11.16（2026-11-16 发布）
  • 安装包：ALTRun_v2026.11.16.zip，1,399,684 字节 ≈ 1.37 MiB
  • 依赖：零运行时依赖，解压即跑，无需装 AutoHotkey
  • 权限：普通用户即可，不需要管理员；无后台服务、无驱动
  • 隐私：不写注册表，数据默认留本机；剪贴板历史在 %LOCALAPPDATA%\ALTRun，不会跟着同步盘或 U 盘副本走

作为对照：Wox 官方 README 自己写着「日常约 150 MB 内存常驻」——这不是骂人，是原生应用诚实的成本。ALTRun 是 AutoHotkey 打包，常驻内存通常是个位数到几十 MB 量级（官方未公布具体数字，我这不装环境实测，只给量级参考）。

我的判断：小，不是卖点本身。「小到可以随便装在公司电脑、家里老机、客户的破笔记本上，还不硌应人」才是。这一点上 ALTRun 比三个对手都舒服。

拼音首字母：中文场景的真正杀招

英文启动器有个天生的墙：Visual Studio Code 你想打 vscode，得记缩写。中文更糟——「微信」就是两个汉字，没有首字母可缩。

ALTRun 的做法是借 pypinyin 的词表（README 致谢里点名了）：

  • wx → 微信
  • jsb → 记事本
  • cs → 测试文件.zip（文件名同样生效）
  • vsc → Visual Studio Code（单词首字母也认）

匹配的部分会高亮。实际体验是：你不需要「记住」任何缩写，想到中文词的首字母直接敲就行。这一点 Wox 靠插件能勉强做，uTools 有中文插件市场，但开箱即用、无需配置的只有 ALTRun。

还有一个细节很戳我：呼出时会自动切到英文输入法。中文用户都懂那个痛——已经按了 Alt+Space，结果打出来是「微信」三个汉字，还得先切状态。这个动作很小，但它说明作者是真的在自己身上用过。

Everything、Listary、剪贴板：三个绝活一次性说清

1. Everything 联动：有就用，没有就内置

装上 Everything，ALTRun 直接用它的索引搜全盘，毫秒级。没装也不至于瘸腿——它有自己的内置索引兜底，只是速度和覆盖不如 Everything。

我在旧文《Everything vs Listary vs uTools vs Fluent Search：4 款桌面搜索工具 2026 实测对比》里测过：Everything 索引 40 万文件约 18 秒，之后搜索延迟 1ms 上下。ALTRun 等于把这份能力「借」过来用——你要么已经有 Everything，要么值得为它装一个。

2. Quick Switch：打开/保存对话框的救星

这是我从 Listary 那儿继承过来的习惯，也是 ALTRun 最被低估的功能。

场景：你在 IDE 里点「另存为」，弹出一个标准 Windows 对话框，路径默认在 C:\Users\...\Documents。你的工程在 D:\Projects\demo。于是你一层层点：此电脑 → D → Projects → demo。点五次。

ALTRun 里按 Ctrl+G，对话框直接跳到 Total Commander / Directory Opus / 资源管理器当前已打开的目录。对话框旁边还会列出最近用过的文件夹面板，收藏的文件夹在星形菜单里。

一天省下的五次点击不值钱，但一年下来那种「系统又在跟我作对」的烦躁感会被削掉一大块。这类功能没有它也能活，有了就回不去。

3. 剪贴板历史：文字、文件、图片都记

Ctrl+Alt+C 或直接输入 clip 唤出剪贴板历史。除了文本，还记录文件和图片；粘贴的那条留在剪贴板里，接着 Ctrl+V 就行；常用条目可置顶，可纯文本粘贴。

一个我欣赏的细节：它自动忽略密码管理器复制的内容。这不是技术难点，是意识问题——大部分同类工具在这一项上是空白。

多合一：它还想替你关掉几个标签页

ALTRun 的定位不是「启动器」，是「键盘操作入口」。README 里列的内置能力包括：

  • 计算器 + 单位换算（10 km in mi）、进制换算（255 in hex）、日期加减（today + 30 days）、可选汇率换算
  • 网页搜索（g 关键词 / bd 关键词，可自定义搜索引擎）
  • 浏览器书签与历史记录（Chrome / Edge / Brave / Vivaldi）
  • 切换窗口（w 关键词）
  • 系统命令（锁屏、睡眠、关机、音量媒体控制、40 多个 Windows 设置页）
  • 文字片段（;关键字 展开，支持 {date} {clipboard} {cursor} 占位符）
  • 终端（>ipconfig /all 直接跑）
  • 脚本扩展：Scripts\ 丢进 .ahk / .ps1 / .bat / .py 即可被搜索调用，支持参数、后台运行、热键绑定

踩坑提示：功能多意味着设置项多。我建议第一次用只做三件事——设热键、开 Everything 联动、挑一套主题（内置 22 套，每套宽松/常规/紧凑三档密度）。别的等真实卡住你了再开，否则会淹死在偏好设置里。

为什么一个「保姆级」项目值得信任

README 里有一句不太起眼的话：每个 Pull Request 都会在 Windows 上自动运行 8,000 余项测试。

我查了 changelog，从 2026.11.16.21 到 2026.11.16.24，同一天连发四个测试版，修的是「两块屏幕缩放比例不同时文件夹面板跑到很远」「远程桌面里片段被本机误展开」这类极其具体的边界问题。维护者只有一个人（zhugecaomao），Issues 里几乎每条建议都有回复。

对比一下规模：Wox ~27,700 star，ALTRun ~350 star。Star 差 80 倍，但那是生态差距，不是质量差距。 单人项目的好处是——你提一个中文场景的 bug，三天后它可能就在 nightly 里修好了。坏处也明显：bus factor 是 1，作者哪天不干了就没了。GPL-3.0 至少保证代码还在，社区能接。

小众软件那篇文章下有句评价我很认同：很少见这样用爱发电的开发者。勤奋不是护城河，但「作者自己每天都在用」是。

什么时候不该选它

别被「小而美」冲昏头，这几种情况请直接绕开：

  • 你要跨平台：ALTRun 只有 Windows。macOS 看 Raycast / Alfred，Linux 看 Albert / Rofi / Ulauncher。
  • 你要成熟插件市场：uTools 的中文插件生态目前仍是国内最强，Wox 的插件商店也更成体系。ALTRun 的扩展是「丢脚本进目录」这种极客模式。
  • 你要团队协作 / 云同步配置：ALTRun 明确把数据留在本机，剪贴板历史不跟同步盘走。多人多设备协同不是它的设计目标。
  • 你想要「装上就不管」：它更新很勤（CHANGELOG 显示几乎每周有构建），但对一部分人来说，勤 = 烦。自动更新会在搜索窗口提示，Enter 即可安装，且校验 SHA256、保留设置。

常见问题

Q1: ALTRun 和 2016 年就停更的那个 ALTRun 是同一个吗？

A: 不是。老的 ALTRun 是 Pascal 写的，仓库 etworker/ALTRun，最后 push 停在 2016-04-01，无许可证。新的是 AutoHotkey 版，作者 zhugecaomao，仓库 2023-07-24 创建，GPL-3.0，2026 年仍在高频更新。同名不同物，别下错。

Q2: 只支持 Windows 吗？

A: 是。官方定位 Windows 10 / 11，无 macOS / Linux 计划。跨平台需求看 Wox（Go 原生，已覆盖三平台）。

Q3: 不装 Everything 能用文件搜索吗？

A: 能，走内置索引。但官方推荐装 Everything——它的 NTFS USN Journal 实时索引是这类工具的共同底座，装上之后搜索是全盘毫秒级。

Q4: 剪贴板历史会不会泄露密码？

A: 默认自动忽略密码管理器复制的内容；剪贴板历史存在 %LOCALAPPDATA%\ALTRun，不随同步盘或便携副本走。涉及敏感内容仍建议自查偏好设置里的相关开关。

Q5: 需要管理员权限吗？

A: 不需要。普通用户可装可用，不写注册表。唯一例外是「在以管理员身份运行的程序里使用 Quick Switch」，官方用一个小助手进程完成跳转，ALTRun 主体仍是普通权限。

Q6: 怎么升级？会自动更新吗？

A: 新版本会在搜索窗口提示，按 Enter 安装，更新包校验 SHA256 并保留设置。也支持 winget install zhugecaomao.ALTRun 和 Scoop（scoop bucket add altrun https://github.com/zhugecaomao/ALTRun）。注意 winget 走微软审核，一般滞后 1–3 天。

Q7: 它安全吗？会被杀软误报吗？

A: 免费版有 SignPath.io 提供的代码签名（仅 Release workflow 构建的 ALTRun.exe 签名）。官方 FAQ 专门有「杀毒软件报毒」条目，遇到 SmartScreen 拦截点「更多信息 → 仍要运行」。源码 GPL 开放可自审。
