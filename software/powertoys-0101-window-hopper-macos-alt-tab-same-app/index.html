Windows 抄 macOS 抄了 5 年，PowerToys 0.101 这次终于抄到了精髓

先说一个每天都在发生的场景。

你在 Chrome 里同时开着三个窗口：一个是文档，一个是 GitHub，一个是查资料的十几个标签页。你想从"文档"切到"GitHub"那个窗口，按下 Alt + Tab。

结果呢？桌面上所有开着的东西全冒出来了——两个 VS Code、一个微信、一个 QQ、一个网易云、一个 Excel、一个 Steam。你要在这一大堆缩略图里眯着眼找那个 GitHub 图标。找到了，松手，切过去。

三秒。看起来不长。

但是这个动作你一天做几十次。每次切浏览器窗口都要看一眼整个桌面，每次切资源管理器都要在十几个窗口里"扫雷"。这种低效是隐性的，你不会觉得难受，你只会觉得"好像有点累"。

Alt + Tab 的设计从 Windows 3.0 就是这样。三十多年了。它按应用不分组、按窗口不分应用，一视同仁全平铺。

macOS 早就有解法：Cmd + Tab 切应用，Cmd + （反引号）切当前应用的多个窗口。两个键管两件事，泾渭分明。用过 Mac 的人回到 Windows，第一件事就是问"这个功能哪去了"。

答案是：没有。第三方工具补丁式实现过，但一直没有官方方案。

直到 2026 年 8 月 25 日，微软发布 PowerToys 0.101。

Window Hopper：Windows 版的 Cmd+`

PowerToys 0.101 里最重要的新增就是 Window Hopper——这个名字翻译过来叫"窗口跳跃"，本质就是给 Windows 补上了那个 macOS 已经用了几十年的功能。

它的工作方式一句话说完：

Alt + （反引号，键盘 Tab 上面那个键）在当前应用的多个窗口之间循环切换。

关键就在"当前应用"这四个字。

举个例子：

  • 你在 Chrome 的某个窗口里，按 Alt + `，只有其他 Chrome 窗口出来，微信 QQ VS Code 全部不打扰你
  • 你在 File Explorer 里，按 Alt + `，只有其他文件夹窗口出来，浏览器视野被隔离
  • 你在 Windows Terminal 里同时开了四个 tab 的多窗口，按 Alt + `，就在这四个终端之间转

它不是替代 Alt + Tab。它是给 Alt + Tab 打了个补丁。

Alt + Tab 继续管跨应用切换，Window Hopper 管应用内切换。两个键分工明确，一个负责"我要换个软件干活"，一个负责"我要换个同类窗口继续这个软件干活"。

这就是 macOS 的哲学。用户在做什么事情，比用户在用什么软件更重要。

为什么这个功能这么"晚"才来

按理说这不是难做的功能。Window Hopper 底层无非就是：

  1. 枚举当前进程（或者 process family）的所有顶层窗口
  2. 按最近使用顺序排一下
  3. 快捷键触发时弹一个小切换器

技术上没有任何障碍。macOS 三十年前就这么做了。第三方工具比如 AltSnap、AquaSnap、Groupy 也都做过类似效果，Groupy 甚至还收费卖了很多年。

真正的问题是微软自己不觉得这是问题。

Windows 的原生窗口模型和 macOS 从一开始就不一样。macOS 把"应用"当一等公民（一个应用可以没有窗口但还开着），Windows 把"窗口"当一等公民（关掉窗口通常就等于退出应用）。这种基因决定了 macOS 天然要考虑"同一应用的多窗口如何切"，Windows 就没这个必要。

结果是：Windows 用户默认习惯了在几十个平铺的缩略图里扫描目标，用了几十年，几乎没人抱怨。直到大家开始双屏、超宽屏，同时开五六个 Chrome、三四个 VS Code、七八个资源管理器，才发现这个默认交互实在扛不住了。

PowerToys 团队在 0.101 里补上这个坑，某种程度上是承认了：当年抄 macOS 抄错了地方，Alt + Tab 该重构了。

不只是 Window Hopper

Window Hopper 是头条，但 0.101 这次一并塞进来的东西还挺多，值得单独拎出来说几个我认为最实用的。

Command Palette 有紧凑模式了

Command Palette 是 PowerToys 里那个"按 Win + Alt + Space 弹出的搜索框"，功能类似 macOS 的 Spotlight 或 Alfred，可以打开程序、算数学题、跑插件命令。

之前它是一个中等尺寸的浮层，占屏幕不小。0.101 加了 Compact Mode（紧凑模式），把这个面板缩得非常小，只留搜索框和最少的候选。适合超宽屏用户或者不喜欢弹窗遮挡视线的人。

Advanced Paste 用上了本地 AI

Advanced Paste 允许你把剪贴板内容"变形"再粘贴——比如把 Markdown 转成纯文本、把 JSON 格式化、让 AI 给你翻译或改写。以前它默认走的是云 API。

0.101 加了 Phi Silica 作为本地推理提供者，前提是你有 Copilot+ PC（也就是带 NPU 的 ARM 设备或最新 Intel Core Ultra）。它意味着：

剪贴板里的内容不用出你的电脑就能完成 AI 转换。

对处理公司内部文档、敏感截图、私人聊天记录的人是刚需。

Shortcut Guide 内嵌了搜索

按住 Win 键一会不放，会弹出所有 Windows 快捷键的图鉴，这是 v0.100 就加的功能。0.101 给它加了搜索框——你不用再肉眼扫图鉴找"最小化窗口"是哪个组合了，直接搜关键词。

Mouse Highlighter 现在有涟漪效果

之前定位鼠标要么开高对比度指针，要么用 PowerToys 的 Mouse Highlighter 把整个屏幕暗下来只让鼠标周围亮。0.101 加了 Ripple 涟漪效果：每次点击时鼠标位置出现一圈扩散的波纹，可以调大小、强度、持续时间。

对做视频教程、直播讲课、屏幕演示的人非常友好——观众不用再猜"你到底点了哪里"。

Quick Accent 支持长按输入

Quick Accent 是给你输入带音标的字符（比如 é、ñ、ü）的工具。之前是按住字母 + 按空格键的方式。0.101 加了 Press-and-hold 模式：像 iOS 长按字母那样，按住字母不放就弹选项，方向键/空格选，松开插入。用惯手机键盘的人会觉得自然。

怎么安装、怎么升级

如果你已经装了 PowerToys，打开设置里的"检查更新"直接升到 0.101 就行。没装过的话，两条路：

方式一：Microsoft Store

打开 Store 搜 “PowerToys”，认准发行商是 Microsoft Corporation，装完自动加入 Windows 更新流。

方式二：GitHub Release

去 github.com/microsoft/PowerToys/releases 找 0.101 的最新版本（写作时是 0.101.2362.0），下载对应架构的 .exe：

  • PowerToysUserSetup-0.101.xxxx.x-x64.exe — 你 90% 的情况选这个
  • PowerToysUserSetup-0.101.xxxx.x-arm64.exe — 骁龙笔记本、Surface Pro X 之类

装完之后进设置，滚到 Window Hopper，打开开关。默认快捷键是 Alt + `（Alt + 反引号），觉得别扭可以改成任何你顺手的组合。

Insider 通道：0.101 还重做了更新体验，现在正式支持 Stable 和 Insider 两条通道。想抢先玩测试版特性的可以切到 Insider，愿意求稳的默认 Stable 不动。

一个小小的调整建议

反引号 ``` 这个键在 US 键盘上位置还行（Tab 键上面），但在 AZERTY 键盘或者某些国家/地区键盘上不太顺手。中文键盘倒是没大问题。

如果你右手常年握鼠标，左手按 Alt + ` 又要伸食指到键盘左上角，其实有点别扭。我个人推荐改成：

  • Ctrl + ~ 或 Ctrl + `（如果没和其他快捷键冲突）
  • Alt + Q （左手位置更舒服）
  • Win + ` （利用 Win 键做区隔）

改的路径：PowerToys 设置 → Window Hopper → Activation shortcut → 点一下自己按新组合。

那些第三方工具怎么办

在 Window Hopper 出现前，Windows 上补这个功能的路子主要是：

  • AltSnap（免费开源）：主打窗口拖拽和吸附，附带一些切换功能，但不专门做"同应用切换"
  • AquaSnap（免费/付费）：吸附增强，切换体验一般
  • Groupy（Stardock，收费约 $10）：把不同窗口组成标签页，某种意义上更强，但改变了原生窗口模型
  • VirtuaWin / bug.n：更极客的窗口平铺方案

如果你只是想要"应用内切换"这一个功能，Window Hopper 直接替代所有第三方方案。它是官方出品、没广告、开源、免费、集成在 PowerToys 里，安装维护成本几乎为零。

如果你还需要窗口标签化（多个窗口合并成 Chrome 那种标签页形态），Groupy 依然有价值。但如果 Groupy 的唯一用途在你这里就是"应用内切换"，可以卸掉了。

一个更大的信号

Window Hopper 单看是一个小功能。放到 PowerToys 这五六年的进化线上看，它代表的是一个方向：

微软终于开始正视 Windows 交互层的"细节积重"了。

过去二十年，Windows 团队做的最大工作是"加东西"：加 Cortana、加 Widgets、加 Copilot、加 AI Recall。这些是宏叙事级别的功能，用来支撑发布会 keynote 的东西。

但用户每天真正在乎的其实是这类东西：

  • Alt + Tab 能不能更聪明
  • 一次能不能同时 rename 一堆文件
  • 剪贴板能不能记住上一份内容
  • 图片能不能直接右键 resize
  • 鼠标能不能大屏时找得到
  • 快捷键能不能有个总览图

而这些"每天都在乎"的东西，从 Windows 官方系统里几乎从来没得到过正视。所有解法都来自民间工具或者 PowerToys 团队这种"半官方半社区"的产品。

PowerToys 从 Windows 95 时代那个"额外工具集"重启到现在的第六年，慢慢在做一件事：把 Windows 里那些本该原生就有的功能一个个补回来。

  • FancyZones 补的是分屏
  • PowerRename 补的是批量重命名
  • Text Extractor 补的是 macOS 的文字提取
  • PeekDesktop（第三方，非 PowerToys）补的是 macOS 的显示桌面
  • 现在 Window Hopper 补的是 Cmd + `

一句话总结：Windows 抄 macOS 抄了 5 年，PowerToys 0.101 这次终于抄到了精髓。

如果你还没装 PowerToys，趁这次更新装上。它不会让你的电脑变得更快，但会让你每天多几十次"这个操作居然这么顺"的小惊喜。

而那些"操作变顺"的时刻累加起来，就是效率工具存在的全部意义。
