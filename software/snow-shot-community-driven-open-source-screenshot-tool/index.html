截图工具是红海中的红海。ShareX 功能最全，PixPin 跨平台体验好，CleanShot X 是 macOS 付费标杆，Snipaste 靠贴图起家。每一款都有明确的商业逻辑或公司背书。

2026 年 10 月，小众软件推荐了一款不太一样的截图工具：Snow Shot。它不是公司出品，不是个人开发者单打独斗，而是社区共同开发——“我们相信最好的软件一定是忠于用户社区的”。

没有高级版，没有 Pro 功能，没有会员。前端应用和后端服务全部开源，GitHub 上找得到每一行代码。

TL;DR

  • Snow Shot 是社区驱动的开源截图工具，v1.1.4，2026-09-27 更新
  • 功能：智能框选、全屏截图、滚动截图、固定到屏幕、OCR、AI 翻译、图片转 HTML/Markdown
  • 插件系统保持核心简洁，扩展功能通过插件加载
  • 前后端全开源，API 服务也能自己部署
  • 全部免费，无会员/Pro/高级版
  • 坑：仅 Windows、社区驱动开发节奏不稳定、AI 翻译依赖后端 API

Snow Shot 是什么？——社区驱动的截图工具

Snow Shot 的官方介绍只有一句话：“Snow Shot 是 Snow Shot 社区共同开发的一款开源截图工具”。

这个定位在截图工具里几乎独一份。ShareX 是 lin_link 个人维护，PixPin 是公司运营，CleanShot X 是付费商业软件，Snipaste 是个人开发者。Snow Shot 把"社区"写进了产品名字里。

GitHub 仓库 mg-chao/snow-apps 包含 Snow Shot 和 Snow Image Viewer 两个应用。2026 年 9 月 6 日首次提交，9 月 27 日发布 v1.1.4。小众软件 10 月 6 日推荐。

功能清单：截图只是起点

Snow Shot 的功能列表读起来像一份"截图工具需求合集"：

  • 智能框选：自动识别窗口边界
  • 一键全屏截图
  • 滚动截图（长截图）
  • 截图固定到屏幕（贴图功能）
  • OCR 提取图片文本：基于 PaddleOCR，Rust 编写（paddle-ocr-rs）
  • AI 翻译：截图后直接翻译文字
  • 图片翻译：图片中的文字直接翻译
  • 图片转为 HTML：截图转结构化 HTML
  • 图片转为 Markdown：截图转 Markdown 格式

OCR 是 MIT 协议开源的，用 Rust 调用 PaddleOCR。AI 翻译和图片翻译依赖后端 API 服务——这个 API 服务也开源了，有技术能力的用户可以自己部署。

插件系统：核心简洁，扩展无限

Snow Shot 的设计哲学是"保持应用本身简洁的同时保持超丰富的扩展功能"。

核心只保留截图、框选、贴图等基础功能。OCR、AI 翻译、图片转 HTML/Markdown 等高级功能通过插件加载。用户按需安装，不想要的可以不装。

这个思路和 VS Code 的插件系统类似：核心轻量，功能通过插件扩展。好处是安装包小、启动快、界面干净；坏处是插件质量参差不齐，需要用户自己筛选。

前后端全开源：API 服务也能自己跑

大多数截图工具的 AI 功能依赖闭源后端。Snow Shot 把 API 服务也开源了。

官方论坛里，开发者提到：“现在之所以用 API 提供服务的方案是因为软件还需要面向普通用户推广，开箱即用的方案还是挺爽的。当用户量多了，倒是也会推出多种方案满足各类用户需求。”

这意味着：

  • 普通用户：开箱即用，AI 翻译直接可用
  • 技术用户：可以自己部署 API 服务，不依赖官方后端
  • 未来可能：客户端加 API 配置功能，用户自定义接口

开发者还提到想集成 Claude，但"用一个封一个"——这反映了 AI 接口的脆弱性，也解释了为什么开源 API 服务是更稳妥的选择。

和现有截图工具比，Snow Shot 的位置在哪？

工具 开发模式 平台 价格 核心优势 适合谁
ShareX 个人维护 Windows 免费开源 功能最全，工作流可配置 高级用户
PixPin 公司运营 Win/macOS 免费+付费 跨平台，AI 功能 普通用户
CleanShot X 商业公司 macOS 付费 体验最好，滚动截图 macOS 付费用户
Snipaste 个人开发者 Win/macOS 免费+付费 贴图功能 贴图重度用户
Snow Shot 社区驱动 Windows 免费开源 插件系统，前后端全开源 社区理念认同者

一句话版本：要功能全选 ShareX，要跨平台选 PixPin，要体验选 CleanShot X，要社区驱动和插件系统选 Snow Shot。

社区驱动的优势与不确定性

社区驱动开发模式在截图工具领域很少见，它的优势和风险都很明显：

优势：

  • 没有商业压力，不会突然加会员/Pro
  • 功能需求来自社区反馈，不是产品经理拍脑袋
  • 代码开源，社区可以贡献插件和功能
  • 前后端全开源，不依赖单一开发者

不确定性：

  • 开发节奏不稳定，可能突然停更
  • 社区决策效率低，功能优先级可能反复
  • 插件质量参差不齐，需要用户自己筛选
  • 仅 Windows，macOS/Linux 用户只能观望

我的建议

认同社区驱动理念、用 Windows 的用户：Snow Shot 值得试。插件系统让核心保持简洁，前后端全开源意味着不会被"突然收费"。

需要跨平台或 macOS 的用户：PixPin 或 CleanShot X 是更成熟的选择。

高级用户/工作流重度用户：ShareX 仍然是功能最全的选择，Snow Shot 的插件系统还在早期，工作流配置不如 ShareX 灵活。

常见问题

Q1: Snow Shot 收费吗？

A: 不收费。全部免费，无高级版、无 Pro、无会员。前后端全开源。

Q2: 支持哪些平台？

A: 目前仅 Windows 10/11。macOS 和 Linux 暂不支持。

Q3: OCR 是离线的吗？

A: OCR 基于 PaddleOCR，Rust 编写，MIT 协议开源。AI 翻译和图片翻译依赖后端 API，但 API 服务也开源了，可以自己部署。

Q4: 插件系统怎么用？

A: 核心只保留基础截图功能，OCR、AI 翻译、图片转 HTML/Markdown 等通过插件加载。用户按需安装。

Q5: 社区驱动是什么意思？

A: 不是公司出品，不是个人开发者单打独斗，而是社区共同开发。功能需求来自社区反馈，代码开源，社区可以贡献。

Q6: 和 ShareX 比有什么优势？

A: ShareX 功能最全但体积大、界面复杂。Snow Shot 插件系统保持核心简洁，社区驱动不会突然收费，前后端全开源。

Q7: 数据安全吗？

A: 前后端全开源，代码可审计。API 服务可以自己部署，不依赖官方后端。
