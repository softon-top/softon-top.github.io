Typora 89 元 / 3 台设备，我找到一个 8.37MB 的单 EXE 替代：Shazao 沙枣

Typora 中文站写着：89 元 / 3 台设备 / 免费升级。

英文站更直白：$14.99（不含税），15 天试用，最多 3 台设备。

这是 Markdown 编辑器里最贵的一档——不是订阅，是买断，但只买断 3 台。家里一台、公司一台、笔记本一台，刚好卡死。第 4 台开始，要么再掏一次钱，要么忍。

于是我在小众软件发现频道里翻到一个叫 Shazao（沙枣）的东西：8.37MB 单 EXE，Windows 原生，免费，不用注册登录，C++20 写的，不基于 Electron。

它真的能替 Typora 吗？我把 GitHub 发布页、README、论坛原帖和 Typora 官方定价全翻了一遍。

TL;DR

  • Shazao 是 Windows 原生 Markdown 阅读/编辑器，单 EXE，C++20 + Win32/DirectWrite/Direct2D/WIC，非 Electron，免费无需登录。
  • 最新稳定版 v0.6.19（11 月 7 日），EXE 9.24MB、UPX 压缩版 3.51MB；小众软件标题写 8.37MB 是旧版体积。
  • 功能对标 Typora 的所见即所得 + Mermaid + 多格式导出，额外有历史版本恢复、富文本粘贴、阅读位置记忆。
  • 硬伤：不开源、只发 Windows EXE、macOS/Linux 直接劝退；v0.6.x 阶段窗口记忆、代码块编辑仍被吐槽。
  • 我的判断：Windows 用户想从 Typora 省钱迁出，可以试；跨平台、要审计源码、要生态插件的，别迁。

为什么我又开始找 Markdown 编辑器？

Typora 的定价不是问题，是"卡 3 台"这件事。89 元 / 3 台，平均一台 29.67 元，比一杯星巴克贵不了多少。真正难受的是：换机、修电脑、公司电脑、家里台式机、随身笔记本——现代人有 3 台以上设备太正常了。

Typora 英文站写得很清楚：$14.99 (without tax)，15 days free trial / up to 3 devices。中文站：89 元 / 3 台设备 / 免费升级。

也就是说，Typora 的商业模式是"买断，但按设备数卖"。这不是它的错，是它的选择。只是这个选择，在 2026 年会让一部分人开始找替代。

另一个背景是：Markdown 编辑器在 2026 年 10-11 月突然井喷。小众软件发现频道一个月里连发 NoteLoom、Shazao、EasyView_Md、Textus、MKnote、MDNote、OpenMarkdown 七款。这个赛道从来没这么挤过。

Shazao（沙枣）到底是个什么东西？

GitHub 仓库：yakoye/Shazao-markdown。167 stars，4 forks，13 个 open issues，2026 年 9 月 18 日创建，最近一次 push 是 11 月 9 日。

注意：没有 license 字段。README 里写得很明白——“目前项目暂不开源，只发布 Windows 可执行程序。GitHub 主要用于版本说明、软件下载以及问题反馈。”

所以它不是开源软件，是"用 GitHub 发免费 EXE"的软件。这一点后面还要说。

技术栈是它最硬的部分：

  • C++20
  • Win32 API
  • DirectWrite（文字排版）
  • Direct2D（绘图）
  • WIC（图像编解码）
  • 不基于 Electron
  • 不需要 WebView2
  • 保持单 EXE

对，这是一份 2026 年极其少见的"原生 Windows"清单。当所有编辑器都在套 Electron 或 Tauri 的时候，有人用 C++20 手搓了一个。

README 里开发者说，他最在意的是"打开速度、滚动、输入响应和大文档性能"，所以开发过程中做了不少自动化、回归和性能测试。

它跟 Typora 的关键区别在哪？

维度 Typora Shazao（沙枣）
价格 中文站 89 元 / 3 台；英文站 $14.99（不含税） 免费，无需注册登录
平台 macOS / Windows / Linux 仅 Windows 10/11 64 位
内核 Electron C++20 + Win32，非 Electron，无需 WebView2
安装形态 安装包 单 EXE，无需安装
开源 否 否（GitHub 只发 EXE）
编辑模式 实时预览（所见即所得） 所见即所得 + 源码模式切换，可锁定阅读
图表/公式 官方 Features 列 Mathematics、Diagrams Mermaid 多图种 + 数学公式
导出 多格式 HTML / PDF / Word / EPUB，可复用 CSS 模板批量导出
特色 主题生态、跨平台、多年口碑 历史版本恢复、富文本粘贴、阅读位置记忆、多标签页

一句话：Typora 赢在跨平台和生态，Shazao 赢在原生、体积和免费。

2026 年 Markdown 编辑器井喷，我把它放进一桌对比

小众软件那篇文章里，编辑顺手列了发现频道最近的 7 款：

工具 小众软件标注时间 一句话
NoteLoom 2026-09-06 浏览器编辑本地 Markdown，兼容 Obsidian
Shazao（沙枣） 2026-10-08 Windows 原生 Markdown 编辑器，单 EXE
EasyView_Md 2026-10-12 Markdown、Office 文档编辑与预览
Textus 2026-10-19 开源跨平台 Markdown 编辑器，集成 AI
MKnote 2026-10-22 Windows Markdown 桌面便签
MDNote 2026-11-02 约 1.3 MB 的免费开源 Markdown 编辑器
OpenMarkdown 2026-11-03 支持 AI Agent 协同编辑 Markdown

（来源：小众软件 2026-11-05 文章，发现频道列表）

在这张桌子上，Shazao 的定位很清晰：原生 Windows + 单 EXE + 免费。Textus 跨平台但集成 AI，MDNote 开源但只有 1.3MB 功能更简，OpenMarkdown 押注 AI Agent 协同。Shazao 押的是"原生性能"这一条路。

免费、单 EXE、C++ 原生：这三个词为什么重要？

Electron 应用的成本是隐形的：Chromium + Node 运行时打进安装包，体积 100MB 起，内存 200-400MB 起。Typora 自己也是 Electron 应用——它把这份成本转嫁给了每个用户。

Shazao 走的是另一条路。GitHub 发布页的实际数据（字节数，我按 1000 进制换算）：

  • v0.6.19 Shazao-markdown.exe：9,243,136 字节 ≈ 9.24 MB
  • v0.6.19 Shazao-markdown-UPX.exe：3,509,760 字节 ≈ 3.51 MB
  • v0.6.19 Shazao-v0.6.19-win64.zip：7,793,962 字节 ≈ 7.79 MB
  • v0.6.18 Shazao-markdown.exe：8,772,096 字节 ≈ 8.77 MB

所以小众软件标题里的"8.37MB"是旧版体积，现在稳定版已经涨到 9MB 左右。UPX 压缩版能压到 3.5MB，但代价是启动时解压。

论坛里有位用户说得很到位：“不用浏览器内核，放弃支持 html 标签后内存占用真小。” 这就是原生的交换条件——你换来体积和内存，付出的是 HTML 标签支持和扩展性。

免费但不开源，这笔账怎么算？

这是我最犹豫的部分。

Shazao 的 GitHub 仓库没有 license 字段，README 明确"暂不开源，只发布 Windows 可执行程序"。开发者在小众软件论坛的自荐帖里也说：“GitHub 主要用于版本说明、软件下载以及问题反馈。”

翻译成人话：你可以免费用，但你审不了它的代码；如果作者哪天停更，你只能等。

风险有多真实？项目 2026 年 9 月 18 日创建，到今天不到两个月。167 stars，4 forks，13 个 open issues。单人开发。这在开源项目里叫"早期"，在商业项目里叫"还没验证"。

但账本也有好的一面：

  • Markdown 文件本身是纯文本，不锁定
  • 历史、草稿、恢复副本、图片缓存、持久撤销和阅读状态默认存在 %LOCALAPPDATA%\Shazao
  • 你的文档可以随时用任何编辑器打开

也就是说，Shazao 停更 ≠ 你的文档丢失。这是 Markdown 生态的天然护城河，也是它敢做封闭原生应用而不挨骂的原因。

另外，它有微软商店版：Microsoft Store 搜 “Shazao Markdown”，应用 ID 9NTW7MF81L2X。多一个分发渠道，多一份账号可信度。

我建议谁装、谁别装？

建议装：

  • Windows 单平台用户
  • 现在用 Typora，不想再为第 4 台设备付钱
  • 在意内存占用和启动速度
  • 需要历史版本恢复、富文本粘贴转 Markdown
  • 想把 Markdown 当"打开就读、落笔就写"的轻工具

建议别装：

  • macOS / Linux 用户——它只做 Windows 10/11 64 位
  • 需要审计源码、要开源保障的人
  • 重度依赖主题生态和插件的人
  • 重度内嵌 HTML 标签的人（它主动放弃了这个）
  • 想要"一个软件管所有设备"的人

小众软件编辑青小蛙在文章里下的判断是：“替代 Typora 还为时尚早，不过喜欢尝鲜的同学可以试试。”

我同意，并且想补一句：它不是 Typora 的平替，它是"Windows 原生免费 Markdown 工具"这个新物种。 用 Typora 的标准去要求它，会得到失望；用"免费 + 原生 + 轻"的标准去试它，会得到惊喜。

常见问题

Q1: Shazao 免费吗？会不会之后收费？

A: 官方 README 写"免费使用，无需注册或登录"。项目 2026-09-18 创建，目前无任何收费说明。但不开源 + 单人开发，长期承诺无法保证。

Q2: 它能直接替代 Typora 吗？

A: 看需求。Windows 用户、核心需求是 Markdown 读写 + 导出，可以试；跨平台、主题生态、HTML 标签重度用户不行。青小蛙原话：“替代 Typora 还为时尚早。”

Q3: 为什么标题写 8.37MB？

A: 那是小众软件 11-05 文章标题的数字。GitHub 最新 v0.6.19 的 EXE 是 9,243,136 字节（约 9.24MB），UPX 压缩版 3,509,760 字节（约 3.51MB），win64 zip 7,793,962 字节。体积随版本变。

Q4: 它开源吗？

A: 不开源。GitHub 仓库没有 license 字段，README 明确"暂不开源，只发布 Windows 可执行程序"。

Q5: 数据存在哪？换机怎么办？

A: 历史、草稿、恢复副本、图片缓存、持久撤销和阅读状态默认在 %LOCALAPPDATA%\Shazao。Markdown 源文件是你自己的，换机把文件夹带走即可。

Q6: 下载量如何？

A: GitHub 发布页计数（非销量）：v0.6.19 EXE 163、zip 207、UPX 27；v0.6.18 EXE 306、zip 359。项目 167 stars。

Q7: 有微软商店版吗？

A: 有。Microsoft Store 搜 “Shazao Markdown”，应用 ID 9NTW7MF81L2X。
